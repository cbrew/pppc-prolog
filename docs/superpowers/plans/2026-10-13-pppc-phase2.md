# PPPC Phase 2 Implementation Plan: Cost Model and Run Time Prediction

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Parallelize an eligible loop only when the paper's run time prediction (section 4.3.4) says it is faster, report predicted loop times and speedups, and measure the target cost table with a calibration program.

**Architecture:** A cost table file (facts, read as data) is loaded into a dict and passed explicitly. `pppc_predict` costs the labelled routine bodies bottom-up with exact rationals and rewrites unprofitable verdicts between parallel loop detection and transformation. `pppc_calibrate` generates C probes (typed tree nodes printed by codegen), builds and runs them with `library(process)`, and writes a table; a second pack app exposes it.

**Tech Stack:** SWI-Prolog 10.0.2 (devenv), plunit, `library(process)`, rationals (`rdiv`), gcc 16 with OpenMP.

**Spec:** `docs/superpowers/specs/2026-10-13-pppc-phase2-design.md` (builds on the Phase 1 spec).

**Provenance:** every file below was taken from a prototype that passed all tests, and the plan was replayed from `master` (`f7e2a2e`), task by task, with the RED and GREEN results recorded in the `Expected:` lines.

## Global Constraints

- Run every command from the project root inside the devenv shell: `devenv shell -- <command>`.
- SWI-Prolog 10.0.2 from devenv; never the system `/usr/bin/swipl`.
- The cost table is passed as an argument; nothing is asserted (spec section 2).
- Times are exact rationals; round only for display (spec 4).
- Tests never depend on live timings, except the two calibration smoke tests, which check only that a table loads (spec 7.1).
- No yall lambda may mention a variable of its enclosing clause (Phase 1 ruling: its meaning depends on whether `library(yall)` was loaded at compile time); use a named helper.
- Every new source error is a `pppc(_)` term with a message in `messages.pl`; exit status 1 for source and option errors, 2 for internal errors.

## Review Focus

Inputs the spec implies that most plausibly break, each pinned by a test in the task that owns the code:

1. `downto` loops and empty ranges (`for i := 5 to 1`) must give exact trip counts, 0 for an empty range — `test_predict.plt` `downto_counts_trips`, `empty_range_costs_nothing` (Task 2).
2. A recursive function must not make prediction loop forever — `recursion_terminates` (Task 2).
3. `--threads` beyond the largest P measured in the table must extrapolate, and a P between measured points interpolate — `overheads_extrapolate_beyond_table` (Task 2), `overhead_interpolated`, `overhead_extrapolated` (Task 1).
4. A hand-edited cost table with a typo, a negative cost, a duplicate or a missing entry must give a clear error, not a crash — `negative_cost`, `duplicate_entry`, `missing_entry`, `syntax_error`, `missing_file` (Task 1); CLI exit 1 in `missing_cost_table_exit_1` (Task 4).
5. An unprofitable outer loop must not leave its inner loops parallel (nested parallelism), and the parallel code of the Phase 1 regression programs must still be built and run — `inner_loops_stay_nested` (Task 2); the zero-overhead build in `e2e.plt` (Task 4).

```prolog
:- module(pppc_cost,
          [ load_cost_table/2,          % +File, -Table
            default_cost_file/1,        % -File
            required_entry/1,           % ?Key
            op2_cost/5,                 % +Table, +Op, +Left, +Right, -Cost
            op1_cost/4,                 % +Table, +Op, +Type, -Cost
            func_cost/3,                % +Table, +Name, -Cost
            unit_cost/3,                % +Table, +Key, -Cost
            trips/2,                    % +Table, -Trips
            overhead/4                  % +Table, +Kind, +P, -Cost
          ]).
:- use_module(library(apply)).
:- use_module(library(lists)).
:- use_module(library(pairs)).

/** <module> Target cost table

The cost table of the paper (section 4.4.6, "Run Time Prediction"):
the execution time of every construct, in units of one integer
addition, plus the cost of the parallel run time's services.

A table file holds facts, read as data with read_term/3 (never
consulted):

    cost_op2(Op, LeftType, RightType, Cost).
    cost_op1(Op, Type, Cost).
    cost_func(Name, Cost).
    cost(Key, Cost).          % Key: index store loop if call param itor write_item
    default_trips(Trips).     % iterations assumed for unknown loop bounds
    overhead(Kind, P, Cost).  % Kind: fork_join | reduction; one fact per measured P

load_cost_table/2 checks every fact and that every required entry is
present, and returns the table as a dict `cost{...}` from kind to a
list of Key-Cost pairs. The table is passed explicitly to the
predicates that need it: nothing is asserted.
*/

%!  default_cost_file(-File) is det.
%
%   The shipped table, produced by pppc_calibrate on the development
%   machine.
default_cost_file(File) :-
    absolute_file_name(library(pppc/cost/default), File,
                       [file_type(prolog), access(read)]).

%!  load_cost_table(+File, -Table) is det.
%
%   Throws pppc(cost_table_missing(File)) if File cannot be read and
%   pppc(bad_cost_table(File, Culprit)) if it holds a term that is not
%   a valid fact, a duplicate, or lacks a required entry (Culprit is
%   then missing(Key)).
load_cost_table(File, Table) :-
    read_facts(File, Facts),
    foldl(add_fact(File), Facts,
          cost{op2:[], op1:[], func:[], unit:[], trips:[], overhead:[]}, T0),
    forall(required_entry(Key), present(File, T0, Key)),
    get_dict(overhead, T0, Os0),
    msort(Os0, Os),
    put_dict(overhead, T0, Os, Table).

read_facts(File, Facts) :-
    catch(setup_call_cleanup(open(File, read, S),
                             read_all(S, Facts),
                             close(S)),
          E, read_error(File, E)).

read_all(S, Facts) :-
    read_term(S, T, []),
    (   T == end_of_file
    ->  Facts = []
    ;   Facts = [T|Ts],
        read_all(S, Ts)
    ).

read_error(File, error(syntax_error(What), _)) :- !,
    throw(pppc(bad_cost_table(File, syntax_error(What)))).
read_error(File, error(existence_error(source_sink, _), _)) :- !,
    throw(pppc(cost_table_missing(File))).
read_error(File, error(permission_error(_, _, _), _)) :- !,
    throw(pppc(cost_table_missing(File))).
read_error(_, E) :-
    throw(E).

add_fact(File, Fact, T0, T) :-
    (   entry(Fact, Kind, Key, Cost)
    ->  get_dict(Kind, T0, Es),
        (   memberchk(Key-_, Es)
        ->  throw(pppc(bad_cost_table(File, duplicate(Fact))))
        ;   put_dict(Kind, T0, [Key-Cost|Es], T)
        )
    ;   throw(pppc(bad_cost_table(File, Fact)))
    ).

%   entry(+Fact, -Kind, -Key, -Cost) is semidet: Fact is a valid table
%   fact. Its Key is what lookups and required_entry/1 use.
entry(Fact, _, _, _) :-
    \+ ground(Fact), !, fail.
entry(cost_op2(Op, L, R, C), op2, Op/L/R, C) :- cost(C), atom(Op), atom(L), atom(R).
entry(cost_op1(Op, T, C), op1, Op/T, C)      :- cost(C), atom(Op), atom(T).
entry(cost_func(F, C), func, F, C)           :- cost(C), atom(F).
entry(cost(K, C), unit, K, C)                :- cost(C), unit_key(K).
entry(default_trips(N), trips, trips, N)     :- integer(N), N > 0.
entry(overhead(K, P, C), overhead, K/P, C)   :-
    cost(C), memberchk(K, [fork_join, reduction]), integer(P), P > 0.

cost(C) :- integer(C), C >= 0.

unit_key(K) :- member(K, [index, store, loop, if, call, param, itor, write_item]).

%!  required_entry(?Key) is nondet.
%
%   Key is an entry every table must have: op2(Op/L/R), op1(Op/T),
%   func(F), unit(K), trips, or overhead(Kind/1). The operator and
%   function entries are exactly the typings the semantic pass accepts
%   (a unit test checks this).
required_entry(op2(Op/T/T)) :-
    member(T-Ops, [ integer-[+, -, *, div, mod, min, max, =, '<>', <, '<=', >, '>='],
                    real-[+, -, *, /, min, max, =, '<>', <, '<=', >, '>='],
                    boolean-[and, or, =, '<>'] ]),
    member(Op, Ops).
required_entry(op1(Op/T)) :-
    member(Op/T, [(-)/integer, (-)/real, not/boolean]).
required_entry(func(F)) :-
    member(F, [abs, sqr, sqrt, sin, cos, exp, ln, trunc, round, odd, random]).
required_entry(unit(K)) :-
    unit_key(K).
required_entry(trips).
required_entry(overhead(K/1)) :-
    member(K, [fork_join, reduction]).

present(File, T, Entry) :-
    Entry =.. [Kind|Rest],
    ( Rest = [Key] -> true ; Key = Kind ),
    get_dict(Kind, T, Es),
    (   memberchk(Key-_, Es)
    ->  true
    ;   throw(pppc(bad_cost_table(File, missing(Entry))))
    ).

                 /*******************************
                 *           LOOKUPS            *
                 *******************************/

%!  op2_cost(+Table, +Op, +Left, +Right, -Cost) is det.
op2_cost(T, Op, L, R, C) :- lookup(T, op2, Op/L/R, C).

%!  op1_cost(+Table, +Op, +Type, -Cost) is det.
op1_cost(T, Op, Ty, C) :- lookup(T, op1, Op/Ty, C).

%!  func_cost(+Table, +Name, -Cost) is det.
func_cost(T, F, C) :- lookup(T, func, F, C).

%!  unit_cost(+Table, +Key, -Cost) is det.
unit_cost(T, K, C) :- lookup(T, unit, K, C).

%!  trips(+Table, -Trips) is det.
trips(T, N) :- lookup(T, trips, trips, N).

lookup(T, Kind, Key, C) :-
    get_dict(Kind, T, Es),
    memberchk(Key-C, Es).

%!  overhead(+Table, +Kind, +P, -Cost) is det.
%
%   The overhead of Kind at P threads: the measured value, or a linear
%   interpolation between the nearest measured points, or beyond the
%   largest measured P a linear extrapolation from the last two (the
%   last one alone if only one is measured). Cost may be a rational;
%   it is never negative.
overhead(T, Kind, P, C) :-
    get_dict(overhead, T, Es),
    findall(Q-X, member(Kind/Q-X, Es), Points),
    (   memberchk(P-C, Points)
    ->  true
    ;   append(_, [P1-C1, P2-C2|_], Points), P1 < P, P < P2
    ->  C is C1 + (C2 - C1) * (P - P1) rdiv (P2 - P1)
    ;   last(Points, P2-C2),
        (   append(_, [P1-C1, P2-C2], Points)
        ->  C is max(0, C2 + (C2 - C1) * (P - P2) rdiv (P2 - P1))
        ;   C = C2
        )
    ).
```

pppc_message(File, bad_number(L, Text)) -->

pppc_message(File, no_source) -->
    [ '~w: cannot open source file'-[File] ].
pppc_message(File, internal(Pass, Reason)) -->
    [ '~w: internal compiler error in pass ~w: ~p'-[File, Pass, Reason] ].
pppc_message(File, bad_threads(N)) -->

pppc_message(_, cost_table_missing(Table)) -->

:- module(pppc_predict,
          [ decide/5                    % +Routines0, +Table, +N, -Routines, -Prediction
          ]).
:- use_module(library(apply)).
:- use_module(library(lists)).
:- use_module(library(pppc/cost)).

/** <module> Run time prediction and the profitability decision

Implements section 4.3.4 of the paper: the predicted execution time
of a routine body, computed bottom-up over its labelled statements
with the costs of a target cost table (pppc_cost), and the decision
to parallelize an eligible loop only if that is predicted to be
faster.

Times are exact rationals (`rdiv`), so the mean of two branches stays
exact; they are rounded only for display.

Costing predicates take an environment

    env(Table, Routines, Mode, Routine, Stack)

where Routines is the analysed program (pppc_transform's
routine(Name, Labelled, Loops, Reach) list), Mode is `serial` or
par(P, Chosen) (Chosen lists Routine/Label-Reductions for every loop
run in parallel), Routine is the routine whose body is being costed
and Stack the routines whose costing is in progress (to stop at
recursion).
*/

%!  decide(+Routines0, +Table, +N, -Routines, -Prediction) is det.
%
%   Routines is Routines0 with every `parallel` loop whose predicted
%   parallel time at N threads is not less than its serial time
%   changed to serial([unprofitable(Serial, Parallel)]) (times rounded
%   to integers). Prediction is
%
%       prediction(Loops, Serial, Speedups)
%
%   Loops has loop_time(Routine, Line, SerialTime, ParallelTimeAtN) for
%   each loop that was `parallel` in Routines0, Serial is the
%   program's predicted serial time and Speedups is [1-S1, ..., N-SN].
decide(Rs0, Table, N, Rs, prediction(Times, Serial, Speedups)) :-
    maplist(decide_routine(Table, Rs0, N), Rs0, Rs, Timess),
    append(Timess, Times),
    findall(R/P-NR, ( member(routine(R, _, Loops, _), Rs),
                      member(loop(P, _, parallel, Classes), Loops),
                      reductions(Classes, NR) ),
            Chosen),
    program_time(Table, Rs0, serial, Serial),
    numlist(1, N, Ps),
    maplist(speedup(Table, Rs0, Chosen, Serial), Ps, Speedups).

decide_routine(Table, Rs, N, routine(Name, LSs, Loops0, Reach),
               routine(Name, LSs, Loops, Reach), Times) :-
    Env = env(Table, Rs, serial, Name, [Name]),
    foldl(decide_loop(Env, Name, LSs, N), Loops0, Loops, Times, []).

decide_loop(Env, Name, LSs, N, loop(P, L, parallel, Classes), Loop) -->
    !,
    { once(sub_term(lbl(P, For), LSs)),
      stmt_time(Env, lbl(P, For), S),
      reductions(Classes, NR),
      parallel_for_time(Env, For, N, NR, Par),
      (   Par < S
      ->  Loop = loop(P, L, parallel, Classes)
      ;   SR is round(S), PR is round(Par),
          Loop = loop(P, L, serial([unprofitable(SR, PR)]), Classes)
      )
    },
    [loop_time(Name, L, S, Par)].
decide_loop(_, _, _, _, Loop, Loop) --> [].

reductions(Classes, N) :-
    aggregate_all(count, member(_-associative(_), Classes), N).

speedup(Table, Rs, Chosen, Serial, P, P-S) :-
    program_time(Table, Rs, par(P, Chosen), T),
    (   T =:= 0
    ->  S = 1
    ;   S is Serial rdiv T
    ).

program_time(Table, Rs, Mode, T) :-
    routine_time(env(Table, Rs, Mode, program, []), program, T).

                 /*******************************
                 *          ROUTINES            *
                 *******************************/

%   routine_time(+Env, +Name, -Time): the predicted time of one
%   execution of the body of routine Name; 0 for a recursive call.
routine_time(env(Table, Rs, Mode, _, Stack), Name, T) :-
    (   memberchk(Name, Stack)
    ->  T = 0
    ;   memberchk(routine(Name, LSs, _, _), Rs),
        seq_time(env(Table, Rs, Mode, Name, [Name|Stack]), LSs, T)
    ).

call_time(Env, Name, Args, T) :-
    Env = env(Table, _, _, _, _),
    routine_time(Env, Name, TB),
    unit_cost(Table, call, Call),
    args_time(Env, Args, TA),
    T is TB + Call + TA.

%   args_time(+Env, +Args, -Time): evaluating and passing Args.
args_time(Env, Args, T) :-
    Env = env(Table, _, _, _, _),
    unit_cost(Table, param, Param),
    foldl(arg_time(Env, Param), Args, 0, T).

arg_time(Env, Param, A, T0, T) :-
    expr_time(Env, A, TA),
    T is T0 + TA + Param.

                 /*******************************
                 *          STATEMENTS          *
                 *******************************/

seq_time(Env, LSs, T) :-
    foldl(add_stmt(Env), LSs, 0, T).

add_stmt(Env, LS, T0, T) :-
    stmt_time(Env, LS, T1),
    T is T0 + T1.

%   stmt_time(+Env, +Labelled, -Time)
stmt_time(Env, lbl(P, S), T) :-
    Env = env(_, _, Mode, R, _),
    S = for(_, _, _), !,
    (   Mode = par(N, Chosen),
        memberchk(R/P-NR, Chosen)
    ->  parallel_for_time(Env, S, N, NR, T)
    ;   serial_for_time(Env, S, T)
    ).
stmt_time(Env, lbl(_, S), T) :-
    stmt(S, Env, T).

stmt(assign(_, [Target, E], _), Env, T) :-
    Env = env(Table, _, _, _, _),
    expr_time(Env, Target, T1),
    expr_time(Env, E, T2),
    arg(3, Target, Type),
    leaves(Type, N),
    unit_cost(Table, store, Store),
    T is T1 + T2 + N * Store.
stmt(zero_assign(_, [V], _), Env, T) :-
    Env = env(Table, _, _, _, _),
    expr_time(Env, V, T1),
    arg(3, V, Type),
    leaves(Type, N),
    unit_cost(Table, store, Store),
    T is T1 + N * Store.
stmt(if(_, [C, Then, Else], _), Env, T) :-
    Env = env(Table, _, _, _, _),
    expr_time(Env, C, TC),
    unit_cost(Table, if, If),
    stmt_time(Env, Then, TT),
    stmt_time(Env, Else, TE),
    T is TC + If + (TT + TE) rdiv 2.
stmt(while(_, [C, Body], _), Env, T) :-
    loop_time(Env, C, Body, T).
stmt(repeat(_, [Body, C], _), Env, T) :-
    loop_time(Env, C, Body, T).
stmt(compound(_, [LSs], _), Env, T) :-
    seq_time(Env, LSs, T).
stmt(pcall(_, [Name, Args], _), Env, T) :-
    call_time(Env, Name, Args, T).
stmt(write(_, [_, Args], _), Env, T) :-
    Env = env(Table, _, _, _, _),
    unit_cost(Table, write_item, W),
    foldl(arg_time(Env, W), Args, 0, T).
stmt(empty(_, _, _), _, 0).

%   while and repeat: default_trips iterations of body and condition.
loop_time(Env, C, Body, T) :-
    Env = env(Table, _, _, _, _),
    trips(Table, N),
    unit_cost(Table, loop, Loop),
    expr_time(Env, C, TC),
    seq_time(Env, Body, TB),
    T is N * (TB + TC + Loop).

serial_for_time(Env, for(_, [_, F, To, D, Body], _), T) :-
    for_parts(Env, F, To, D, Body, TBounds, Trips, TIter),
    T is TBounds + Trips * TIter.

%   parallel_for_time(+Env, +For, +P, +Reductions, -Time)
parallel_for_time(Env, for(_, [_, F, To, D, Body], _), P, NR, T) :-
    Env = env(Table, _, _, _, _),
    for_parts(Env, F, To, D, Body, TBounds, Trips, TIter),
    overhead(Table, fork_join, P, FJ),
    overhead(Table, reduction, P, Red),
    T is TBounds + ((Trips + P - 1) // P) * TIter + FJ + NR * Red.

for_parts(Env, F, To, D, Body, TBounds, Trips, TIter) :-
    Env = env(Table, _, _, _, _),
    expr_time(Env, F, TF),
    expr_time(Env, To, TT),
    TBounds is TF + TT,
    for_trips(Table, F, To, D, Trips),
    seq_time(Env, Body, TB),
    unit_cost(Table, loop, Loop),
    TIter is TB + Loop.

for_trips(_, iconst(_, [F], _), iconst(_, [T], _), D, N) :- !,
    (   D == up
    ->  N is max(0, T - F + 1)
    ;   N is max(0, F - T + 1)
    ).
for_trips(Table, _, _, _, N) :-
    trips(Table, N).

%   leaves(+Type, -N): the number of scalars in a value of Type.
leaves(array(Lo, Hi, E), N) :- !,
    leaves(E, NE),
    N is (Hi - Lo + 1) * NE.
leaves(record(Fs), N) :- !,
    foldl(add_leaves, Fs, 0, N).
leaves(_, 1).

add_leaves(_-T, N0, N) :-
    leaves(T, NT),
    N is N0 + NT.

                 /*******************************
                 *         EXPRESSIONS          *
                 *******************************/

%   expr_time(+Env, +Expr, -Time), after the paper's cost_expr/2.
expr_time(Env, E, T) :-
    Env = env(Table, _, _, _, _),
    expr(E, Env, Table, T).

expr(id(_, _, _), _, _, 0).
expr(vparam(_, _, _), _, _, 0).
expr(fresult(_, _, _), _, _, 0).
expr(iconst(_, _, _), _, _, 0).
expr(fconst(_, _, _), _, _, 0).
expr(bconst(_, _, _), _, _, 0).
expr(string(_, _, _), _, _, 0).
expr(op2(_, [Op, L, R], _), Env, Table, T) :-
    expr(L, Env, Table, TL),
    expr(R, Env, Table, TR),
    arg(3, L, TyL), arg(3, R, TyR),
    op2_cost(Table, Op, TyL, TyR, C),
    T is TL + TR + C.
expr(op1(_, [Op, E], _), Env, Table, T) :-
    expr(E, Env, Table, TE),
    arg(3, E, Ty),
    op1_cost(Table, Op, Ty, C),
    T is TE + C.
expr(itor(_, [E], _), Env, Table, T) :-
    expr(E, Env, Table, TE),
    unit_cost(Table, itor, C),
    T is TE + C.
expr(index(_, [A, I], _), Env, Table, T) :-
    expr(A, Env, Table, TA),
    expr(I, Env, Table, TI),
    unit_cost(Table, index, C),
    T is TA + TI + C.
expr(field(_, [R, _], _), Env, Table, T) :-
    expr(R, Env, Table, T).
expr(addr(_, [V], _), Env, Table, T) :-
    expr(V, Env, Table, T).
expr(builtin(_, [F, Args], _), Env, Table, T) :-
    func_cost(Table, F, C),
    args_time(Env, Args, TA),
    T is C + TA.
expr(fcall(_, [F, Args], _), Env, _, T) :-
    call_time(Env, F, Args, T).

/** <module> Measure a target cost table

Produces the cost table of pppc_cost on the machine it runs on, as the
paper's "special program, which measures the time needed for the
operations" (section 4.3.4) did:

  1. generate one C program that times every probe: a loop whose body
     repeats one operation of the cost table U times;
  2. build it with gcc -O2 -fopenmp and run it, with library(process);
  3. normalise: the time of one operation is the difference between
     the runs with U = 12 and U = 4, divided by 8 (which cancels the
     loop overhead), in units of one integer addition; take the median
     of the runs.

The expression probes are typed tree nodes turned into C by codegen's
c_expr/2, so they time exactly the C the compiler emits. Operators are
timed as a dependent chain (each result is the next operand), so they
cost their latency and one integer addition is one cycle. Inline asm
barriers between the copies stop gcc folding the chain or removing
the work.

Options: max_threads(N) (default: the number of CPUs), repeat(K)
(default 5), iterations(I) (default 1000000), reps(R), the repetitions
of each OpenMP region (default 2000).
*/

%!  calibrate(+Options, -Facts) is det.
%
%   Measure this machine. Throws pppc(calibrate(Why)) if the C program
%   cannot be built or its output cannot be read.
calibrate(Options0, Facts) :-
    calibration_options(Options0, Options),
    calibration_c(Options, C),
    run_c(C, Options, Output),
    parse_output(Output, Samples),
    normalise(Samples, Options, Facts).

%!  calibration_options(+Options0, -Options) is det.
%
%   Options0 completed with the defaults.
calibration_options(Options0, Options) :-
    current_prolog_flag(cpu_count, CPUs),
    merge_options(Options0,
                  [max_threads(CPUs), repeat(5), iterations(1000000), reps(2000)],
                  Options).

%   The two unroll counts, and the divisor of the iterations for the
%   (slow) output probe.
unrolls(4, 12).
write_divisor(64).

                 /*******************************
                 *            PROBES            *
                 *******************************/

%   probe(?Entry, -Decls, -Copy) enumerates the probes in a fixed order.
%   Entry is the cost table entry measured (see required_entry/1), or
%   call1 (a call with one argument, from which param is derived).
%   Decls lists the Name-Type locals the probe uses (the first is the
%   chain variable). Copy is one copy of the operation:
%
%     - chain(E): p_a = E, so each copy depends on the last;
%     - free(E):  r = E on unchanged operands;
%     - c(Text):  C statements.

probe(unit(loop), [], c("")).
probe(op2(Op/T/T), [a-T, b-T], chain(op2(0, [Op, id(0, [a], T), id(0, [b], T)], R))) :-
    required_entry(op2(Op/T/T)),
    pppc_semantic:op2_rule(Op, T, T, R).
probe(op1(Op/T), [a-T], chain(op1(0, [Op, id(0, [a], T)], T))) :-
    required_entry(op1(Op/T)).
probe(func(F), Decls, free(builtin(0, [F, Args], R))) :-
    required_entry(func(F)),
    once(pppc_semantic:builtin_sig(F, ArgTypes, R)),
    func_args(ArgTypes, Decls, Args).
probe(unit(index), [a-integer],
      chain(index(0, [id(0, [v], array(1, 1024, integer)), id(0, [a], integer)], integer))).
probe(unit(itor), [a-integer], free(itor(0, [id(0, [a], integer)], real))).
probe(unit(store), [a-integer], c("p_s = p_a; PPPC_BAR_MEM(p_s); PPPC_BAR_long(p_a);")).
probe(unit(if), [c-boolean], c("if (p_c) __asm__ volatile(\"\"); PPPC_BAR_bool(p_c);")).
probe(unit(call), [], c("r = pppc_f0(); PPPC_BAR_long(r);")).
probe(call1, [a-integer], c("p_a = pppc_f1(p_a);")).
probe(unit(write_item), [a-integer], c("fprintf(pppc_null, \"%ld\", p_a);")).

func_args([], [], []).
func_args([T], [a-T], [id(0, [a], T)]).

probes(Probes) :-
    findall(p(E, D, C), probe(E, D, C), Probes).

                 /*******************************
                 *          C PROGRAM           *
                 *******************************/

%!  calibration_c(+Options, -CText:string) is det.
%
%   The C program. It is run as `prog Iterations Repeat MaxThreads
%   Reps` and prints, for each repetition, `probe K U Seconds` for every
%   probe K (counting from 0) and unroll count U, and `fork_join P
%   Seconds`, `reduction P Seconds` (seconds per OpenMP region) for P
%   in 1..MaxThreads.
calibration_c(_Options, C) :-
    probes(Probes),
    runtime_text(Runtime),
    unrolls(U1, U2),
    with_output_to(string(C),
                   ( write(Runtime),
                     write_prelude,
                     forall(nth0(K, Probes, P),
                            ( write_probe(K, U1, P), write_probe(K, U2, P) )),
                     write_main(Probes) )).

write_prelude :-
    format("~s", [
"
/* calibration harness */
#if defined(__x86_64__)
#define PPPC_FREG \"+x\"
#elif defined(__aarch64__)
#define PPPC_FREG \"+w\"
#else
#define PPPC_FREG \"+m\"
#endif
#define PPPC_BAR_long(v)   __asm__ volatile(\"\" : \"+r\"(v))
#define PPPC_BAR_bool(v)   __asm__ volatile(\"\" : \"+r\"(v))
#define PPPC_BAR_double(v) __asm__ volatile(\"\" : PPPC_FREG(v))
#define PPPC_BAR_MEM(v)    __asm__ volatile(\"\" : \"+m\"(v))

static volatile double pppc_sink;
static FILE *pppc_null;
static long p_s;
static struct { long e[1024]; } p_v;
__attribute__((noinline, noipa)) static long pppc_f0(void) { return 1; }
__attribute__((noinline, noipa)) static long pppc_f1(long a) { return a; }
"]).

write_probe(K, U, p(_, Decls, Copy)) :-
    copy_text(Copy, Decls, RType, Text),
    format("~nstatic double pppc_probe_~d_~d(long iters)~n{~n", [K, U]),
    forall(member(N-T, Decls),
           ( c_scalar(T, CT, Init), format("    ~w p_~w = ~w;~n", [CT, N, Init]) )),
    c_scalar(RType, RCT, _),
    format("    ~w r = 0;~n    double t0, t1;~n    long k;~n", [RCT]),
    format("    t0 = omp_get_wtime();~n    for (k = 0; k < iters; k++) {~n", []),
    forall(between(1, U, _), format("        ~s~n", [Text])),
    format("    }~n    t1 = omp_get_wtime();~n", []),
    forall(member(N-T, Decls), format("    pppc_sink += (double)p_~w;~n", [N])),
    format("    pppc_sink += (double)r;~n    return t1 - t0;~n}~n", []).

%   copy_text(+Copy, +Decls, -ResultType, -Text): one copy of the
%   operation, as C, and the type of r.
copy_text(chain(E), [A-T|_], integer, Text) :-
    c_expr(E, CE),
    c_scalar(T, CT, _),
    format(string(Text), "p_~w = ~s; PPPC_BAR_~w(p_~w);", [A, CE, CT, A]).
copy_text(free(E), Decls, RType, Text) :-
    arg(3, E, RType),
    c_expr(E, CE),
    c_scalar(RType, RCT, _),
    findall(B, ( member(N-T, Decls), c_scalar(T, CT, _),
                 format(string(B), " PPPC_BAR_~w(p_~w);", [CT, N]) ),
            Bars),
    atomic_list_concat(Bars, BarText),
    format(string(Text), "r = ~s; PPPC_BAR_~w(r);~w", [CE, RCT, BarText]).
copy_text(c(Text), _, integer, Text).

%   c_scalar(Type, CType, Initial value). The values keep every chain
%   finite: a / b, a div b and a mod b stay put with b = 1.
c_scalar(integer, long, '7').
c_scalar(real, double, '1.5').
c_scalar(boolean, bool, true).

write_main(Probes) :-
    length(Probes, N),
    unrolls(U1, U2),
    write_divisor(D),
    format("~nstatic double (*const pppc_probes[~d][2])(long) = {", [N]),
    forall(between(1, N, K1),
           ( K is K1 - 1,
             format("~n    { pppc_probe_~d_~d, pppc_probe_~d_~d },", [K, U1, K, U2]) )),
    format("~n};~n", []),
    nth0(W, Probes, p(unit(write_item), _, _)), !,
    format("static const long pppc_unroll[2] = { ~d, ~d };~n", [U1, U2]),
    format("static const long pppc_write_probe = ~d, pppc_write_divisor = ~d;~n", [W, D]),
    format("~s", [
"
static double pppc_region(int p, long reps, int reduce)
{
    double s = 0, t0 = omp_get_wtime();
    for (long k = 0; k < reps; k++) {
        if (reduce) {
            #pragma omp parallel for num_threads(p) reduction(+:s)
            for (long i = 0; i < p; i++) s += 1.0;
        } else {
            #pragma omp parallel for num_threads(p)
            for (long i = 0; i < p; i++) __asm__ volatile(\"\");
        }
    }
    pppc_sink += s;
    return (omp_get_wtime() - t0) / reps;
}

int main(int argc, char **argv)
{
    if (argc != 5) return 2;
    long iters = atol(argv[1]), reps = atol(argv[4]);
    int repeat = atoi(argv[2]), maxp = atoi(argv[3]);
    long n = sizeof pppc_probes / sizeof pppc_probes[0];
    for (long k = 0; k < 1024; k++) p_v.e[k] = k + 1;   /* p_v.e[a - 1] == a */
    pppc_null = fopen(\"/dev/null\", \"w\");

    pppc_region(maxp, reps, 0);              /* start the threads */
    pppc_probes[0][0](iters);                /* warm up */
    for (int r = 0; r < repeat; r++) {

            printf(\"reduction %d %.9e\\n\", p, pppc_region(p, reps, 1));

    tmp_file(pppc_calibrate, Base),

    format(atom(A), '~w', [X]).

%!  parse_output(+Text, -Samples) is det.
%
%   Samples is a list of Key-Seconds, Key one of probe(K, U),
%   fork_join(P), reduction(P). Throws pppc(calibrate(bad_output(Line)))
%   on a line of another form.
parse_output(Text, Samples) :-
    split_string(Text, "\n", "", Lines0),
    exclude(==(""), Lines0, Lines),
    maplist(sample, Lines, Samples).

sample(Line, Key-Secs) :-
    split_string(Line, " ", "", Fields),
    append([KindS|ArgSs], [SecsS], Fields),
    atom_string(Kind, KindS),
    maplist(integer_string, Args, ArgSs),
    number_string(Secs, SecsS), number(Secs),
    Key =.. [Kind|Args],
    memberchk(Key, [probe(_, _), fork_join(_), reduction(_)]),
    !.
sample(Line, _) :-
    throw(pppc(calibrate(bad_output(Line)))).

integer_string(N, S) :-
    number_string(N, S),
    integer(N).

%!  normalise(+Samples, +Options, -Facts) is det.
%
%   Turn timings into cost table facts. An operation's time is the
%   median over the runs of (time at U2 - time at U1) / (U2 - U1) /
%   iterations; every cost is that time divided by the integer
%   addition's, rounded, at least 1. cost(loop) is one iteration of
%   the empty loop, cost(param) the extra time of a call with one
%   argument. Options gives iterations(I).
normalise(Samples, Options, Facts) :-
    option(iterations(I), Options),
    probes(Probes),
    findall(E-T, ( nth0(K, Probes, p(E, _, _)), op_time(Samples, K, E, I, T) ), Times),
    memberchk(op2((+)/integer/integer)-Add, Times),
    (   Add > 0
    ->  true
    ;   throw(pppc(calibrate(no_signal)))
    ),
    nth0(KL, Probes, p(unit(loop), _, _)), !,
    unrolls(U1, _),
    median(Samples, probe(KL, U1), LoopSecs),
    Loop is LoopSecs / I,
    memberchk(unit(call)-Call, Times),
    memberchk(call1-Call1, Times),
    findall(F, ( member(E-T, Times), entry_fact(E, T, Loop, Call, Call1, Add, F) ),
            Ops),
    findall(F, overhead_fact(Samples, Add, F), Overheads),
    append([Ops, [default_trips(25)], Overheads], Facts0),
    order_facts(Facts0, Facts).

op_time(Samples, K, E, I, T) :-
    unrolls(U1, U2),
    (   E == unit(write_item)
    ->  write_divisor(D), It is I // D
    ;   It = I
    ),
    findall(T1, ( member(probe(K, U1)-S1, Samples), T1 = S1 ), S1s),
    findall(T2, ( member(probe(K, U2)-S2, Samples), T2 = S2 ), S2s),
    pairs_keys_values(Pairs, S1s, S2s),
    findall(D1, ( member(A-B, Pairs), D1 is (B - A) / ((U2 - U1) * It) ), Ds),
    median_list(Ds, T).

entry_fact(unit(loop), _, Loop, _, _, Add, cost(loop, C)) :- !,
    units(Loop, Add, C).
entry_fact(call1, _, _, Call, Call1, Add, cost(param, C)) :- !,
    units(Call1 - Call, Add, C).
entry_fact(E, T, _, _, _, Add, Fact) :-
    units(T, Add, C),
    entry_term(E, C, Fact).

entry_term(op2(Op/L/R), C, cost_op2(Op, L, R, C)).
entry_term(op1(Op/T), C, cost_op1(Op, T, C)).
entry_term(func(F), C, cost_func(F, C)).
entry_term(unit(K), C, cost(K, C)).

overhead_fact(Samples, Add, overhead(fork_join, P, C)) :-
    fork_join_points(Samples, Ps),
    member(P, Ps),
    median(Samples, fork_join(P), T),
    units(T, Add, C).
overhead_fact(Samples, Add, overhead(reduction, P, C)) :-
    fork_join_points(Samples, Ps),
    member(P, Ps),
    median(Samples, fork_join(P), T0),
    median(Samples, reduction(P), T1),
    units(T1 - T0, Add, C).

fork_join_points(Samples, Ps) :-
    findall(P, member(fork_join(P)-_, Samples), Ps0),
    sort(Ps0, Ps).

units(T, Add, C) :-
    C is max(1, round(T / Add)).

median(Samples, Key, M) :-
    findall(S, member(Key-S, Samples), Ss),
    median_list(Ss, M).

median_list(Xs0, M) :-
    msort(Xs0, Xs),
    length(Xs, N),
    N > 0,
    Mid is N // 2,
    (   N mod 2 =:= 1
    ->  nth0(Mid, Xs, M)
    ;   Lo is Mid - 1, nth0(Lo, Xs, A), nth0(Mid, Xs, B),
        M is (A + B) / 2
    ).

%   Facts in the order of the table format: operators, functions,
%   cost/2, default_trips, overheads.
order_facts(Facts0, Facts) :-
    map_list_to_pairs(fact_rank, Facts0, Ranked),
    keysort(Ranked, Sorted),
    pairs_values(Sorted, Facts).

fact_rank(cost_op2(_, _, _, _), 1).
fact_rank(cost_op1(_, _, _), 2).
fact_rank(cost_func(_, _), 3).
fact_rank(cost(_, _), 4).
fact_rank(default_trips(_), 5).
fact_rank(overhead(_, _, _), 6).

                 /*******************************
                 *            OUTPUT            *
                 *******************************/

%!  write_table(+Stream, +Facts, +Options) is det.
%
%   Write Facts as a cost table file, after a header comment recording
%   the machine and the options.
write_table(S, Facts, Options) :-
    get_time(Now),
    format_time(atom(Date), '%F %T', Now),
    cpu_model(CPU),
    gcc_version(GCC),
    format(S, "/*  PPPC cost table, measured by pppc_calibrate~n~n", []),
    format(S, "    Date:    ~w~n    CPU:     ~w~n    gcc:     ~w (-O2 -fopenmp)~n",
           [Date, CPU, GCC]),
    format(S, "    Options: ~q~n~n", [Options]),
    format(S, "    Costs are in units of one integer addition.~n*/~n~n", []),
    forall(member(F, Facts), portray_clause(S, F)).

cpu_model(Model) :-
    catch(read_file_to_string('/proc/cpuinfo', Text, []), _, fail),
    split_string(Text, "\n", "", Lines),
    member(L, Lines),
    string_concat("model name", Rest, L),
    split_string(Rest, ":", " \t", [_, Model|_]),
    !.
cpu_model(unknown).

gcc_version(V) :-
    catch(( process_create(path(gcc), ['-dumpfullversion'],
                           [stdout(pipe(O)), process(Pid)]),
            read_string(O, _, S), close(O), process_wait(Pid, _) ),
          _, fail),
    split_string(S, "", " \n", [V]),
    !.
gcc_version(unknown).

/** <module> Parallelizer driver and loop transformation

Runs the parallelizer phases of the paper (section 4.4.6) over each
routine of a typed program: statement labelling, reaching definitions,
parallel loop detection, run time prediction (pppc_predict), code
transformation and cleanup.

A parallel loop becomes

    omp_for(Line, [Var, From, To, Dir, Body, Clauses], void)

where Clauses is a list of private(Vars), shared(Vars) and
reduction(Op, Vars) terms with non-empty variable lists.
*/

%!  analyse_program(+Typed, -Routines:list) is det.
%
%   Routines has one routine(Name, Labelled, Loops, Reach) per routine
%   (the main program first, named `program`: a reserved word, so no
%   user routine can have the same name). Reach is the sorted list of
%   reach(Var, Def, Use) facts. Used for --dump and --report.
analyse_program(Typed, Routines) :-
    program_routines(Typed, Rs),
    maplist(analyse_routine, Rs, Routines).

%!  parallelize_program(+Typed, -Parallel, -Routines) is det.
%
%   Transform every loop that obeys the parallelization rules, without
%   run time prediction.
parallelize_program(Typed, Parallel, Routines) :-
    analyse_program(Typed, Routines),
    transform_program(Typed, Routines, Parallel).

%!  parallelize_program(+Typed, +Table, +N, -Parallel, -Routines) is det.
%
%   Transform the loops that obey the parallelization rules and are
%   predicted, with cost table Table, to run faster in parallel on N
%   threads. Routines has the final verdicts.
parallelize_program(Typed, Table, N, Parallel, Routines) :-
    analyse_program(Typed, Routines0),
    decide(Routines0, Table, N, Routines, _),
    transform_program(Typed, Routines, Parallel).

transform_program(Typed, Routines, Parallel) :-
    Typed = program(L, [Name, block(BL, [Decls, Procs, Body], void)], void),
    routine_body(program, Routines, Body, NewBody),
    maplist(transform_proc(Routines), Procs, NewProcs),
    Parallel = program(L, [Name, block(BL, [Decls, NewProcs, NewBody], void)], void).

transform_proc(Routines, proc(L, [N, Ps, R, block(BL, [D, P, Body], void)], void),
               proc(L, [N, Ps, R, block(BL, [D, P, NewBody], void)], void)) :-
    routine_body(N, Routines, Body, NewBody).

routine_body(Name, Routines, compound(L, _, _), NewBody) :-
    memberchk(routine(Name, LSs, Loops0, _), Routines),
    maplist(hide_result(Name), Loops0, Loops),
    transform_seq(LSs, Loops, LSs1),
    unlabel_body(LSs1, L, NewBody).

%   A function's result is stored in pppc_result, a C local declared
%   outside the loop and so shared by default; it must not be named in
%   a clause. (The only class it can have in a parallel loop is
%   distributed: reading it is an error, so it is never local or
%   associative.)
%   (A plain helper rather than a yall lambda: a lambda that mentions a
%   variable of the enclosing clause, like Name here, behaves differently
%   depending on whether library(yall) was loaded when this file was
%   compiled, unless the variable is declared with Name/[X]>>... .)
hide_result(Name, loop(P, L, V, Classes0), loop(P, L, V, Classes)) :-
    exclude(class_of(Name), Classes0, Classes).

class_of(Name, X-_) :- X == Name.

                 /*******************************
                 *          ROUTINES            *
                 *******************************/

%   program_routines(+Typed, -Rs): Rs is a list of
%   r(Name, Body, AllVars, ExitVars, CallVars). CallVars are the
%   variables another routine called from this one can reach (and so
%   also those a var parameter of this one might alias): the globals not
%   shadowed here, plus this routine's var parameters.

program_routines(program(_, [_, block(_, [Decls, Procs, Body], _)], _), [Main|Rs]) :-
    decl_names(Decls, Globals),
    Main = r(program, Body, Globals, [], Globals),
    maplist(proc_routine(Globals), Procs, Rs).

proc_routine(Globals, proc(_, [Name, Params, R, block(_, [Decls, _, Body], _)], _),
             r(Name, Body, All, Exit, Call)) :-
    findall(N, (member(param(_, [_, Ns, _], _), Params), member(N, Ns)), PNs),
    findall(N, (member(param(_, [var, Ns, _], _), Params), member(N, Ns)), VNs),
    decl_names(Decls, Locals),
    ( R == none -> Res = [] ; Res = [Name] ),
    foldl(union_list, [PNs, Locals, Res], [], Own),
    ord_subtract(Globals, Own, Visible),
    foldl(union_list, [Visible, Own], [], All),
    foldl(union_list, [Visible, VNs, Res], [], Exit),
    union_list(VNs, Visible, Call).

union_list(L, S0, S) :- sort(L, SL), ord_union(S0, SL, S).

decl_names(Decls, Names) :-
    findall(N, (member(var_decl(_, [Ns, _], _), Decls), member(N, Ns)), Names0),
    sort(Names0, Names).

analyse_routine(r(Name, Body, All, Exit, Call), routine(Name, LSs, Loops, Reach)) :-
    label_body(Body, LSs),
    with_dataflow(LSs, All, Exit, Call,
                  ( classify_loops(LSs, Call, Loops),
                    findall(reach(V, S, U), reach(V, S, U), Reach0),
                    sort(Reach0, Reach) )).

                 /*******************************
                 *        TRANSFORMATION        *
                 *******************************/

transform_seq(LSs, Loops, LSs1) :-
    maplist(transform(Loops), LSs, LSs1).

transform(Loops, lbl(P, for(L, [V, F, T, D, B], Ty)), lbl(P, S)) :- !,
    (   memberchk(loop(P, _, parallel, Classes), Loops)
    ->  clauses(Classes, Clauses),
        S = omp_for(L, [V, F, T, D, B, Clauses], Ty)
    ;   transform_seq(B, Loops, B1),
        S = for(L, [V, F, T, D, B1], Ty)
    ).
transform(Loops, lbl(P, while(L, [C, B], Ty)), lbl(P, while(L, [C, B1], Ty))) :- !,
    transform_seq(B, Loops, B1).
transform(Loops, lbl(P, repeat(L, [B, C], Ty)), lbl(P, repeat(L, [B1, C], Ty))) :- !,
    transform_seq(B, Loops, B1).
transform(Loops, lbl(P, if(L, [C, T, E], Ty)), lbl(P, if(L, [C, T1, E1], Ty))) :- !,
    transform(Loops, T, T1),
    transform(Loops, E, E1).
transform(Loops, lbl(P, compound(L, [B], Ty)), lbl(P, compound(L, [B1], Ty))) :- !,
    transform_seq(B, Loops, B1).
transform(_, S, S).

%!  clauses(+Classes, -Clauses) is det.
%
%   Map the paper's variable categories to OpenMP data-sharing clauses.
clauses(Classes, Clauses) :-
    findall(V, member(V-local, Classes), Private),
    findall(V, ( member(V-C, Classes), memberchk(C, [read_only, distributed]) ), Shared),
    findall(Op-V, member(V-associative(Op), Classes), OpVs),
    keysort(OpVs, Sorted),
    group_pairs_by_key(Sorted, Groups),
    findall(reduction(Op, Vs), member(Op-Vs, Groups), Reductions),
    exclude(==(private([])), [private(Private)], P1),
    exclude(==(shared([])), [shared(Shared)], S1),
    append([P1, S1, Reductions], Clauses).

/** <module> PPPC: a portable parallelizing Pascal compiler

Reproduction of Gabber's PPPC (The Practice of Prolog, 1990, ch. 4)
targeting C + OpenMP. The passes are run in-process:

    lexer -> parser -> semantic -> [parallelizer] -> codegen

The parallelizer decides with the run time prediction for a number of
threads, using a target cost table. Options accepted by pppc_compile/3,
pppc_report/3 and pppc_predict/3:

  - threads(N)  the number of threads to predict for (default 4);
  - cost(File)  the cost table (default: the shipped table).

Errors in the source are thrown as pppc(Error) where Error is
no_source, syntax(Line, Expected, Found), bad_number(Line, Text) or
semantic_errors(List); errors in the options as bad_threads(N),
cost_table_missing(File) or bad_cost_table(File, Culprit); a failing or
crashing pass throws pppc(internal(Pass, Reason)).
*/

%!  pppc_compile(+File, +Options, -CText:string) is det.
%
%   Compile the TAU-Pascal program in File to C. Options, besides
%   threads(N) and cost(File):
%
%     - serial(Bool)  if `true`, skip the parallelizer.
pppc_compile(File, Options, CText) :-
    front_end(File, Typed),
    (   option(serial(true), Options)
    ->  Program = Typed
    ;   prediction_setup(Options, Table, N),
        pass(parallelizer, parallelize_program(Typed, Table, N, Program, _))
    ),
    pass(codegen, generate_c(Program, CText)).

%!  pppc_stage(+File, +Stage, -Result) is det.
%
%   Run the compiler up to Stage and return its output. Stage is one
%   of tokens, parse, typed, labelled, reach, predict, parallel. For
%   labelled and reach, Result is a list Routine-Value. predict and
%   parallel use the default options.
pppc_stage(File, tokens, Ts) :- !,
    read_source(File, Codes),
    pass(lexer, tokenize(Codes, Ts)).
pppc_stage(File, parse, Tree) :- !,
    pppc_stage(File, tokens, Ts),
    pass(parser, parse_program(Ts, Tree)).
pppc_stage(File, typed, Typed) :- !,
    front_end(File, Typed).
pppc_stage(File, labelled, Pairs) :- !,
    analysis(File, Rs),
    findall(N-L, member(routine(N, L, _, _), Rs), Pairs).
pppc_stage(File, reach, Pairs) :- !,
    analysis(File, Rs),
    findall(N-R, member(routine(N, _, _, R), Rs), Pairs).
pppc_stage(File, predict, Prediction) :- !,
    pppc_predict(File, [], Prediction).
pppc_stage(File, parallel, Program) :- !,
    front_end(File, Typed),
    prediction_setup([], Table, N),
    pass(parallelizer, parallelize_program(Typed, Table, N, Program, _)).
pppc_stage(_, Stage, _) :-
    domain_error(pppc_stage, Stage).

%!  pppc_report(+File, -Lines:list(string)) is det.
%!  pppc_report(+File, +Options, -Lines:list(string)) is det.
%
%   One line per for loop:
%
%       Routine Line parallel Var:Class ...
%       Routine Line serial Reason ...
%       Routine Line nested OuterLine
%
%   Reason unprofitable(Serial, Parallel) gives the predicted times.
pppc_report(File, Lines) :-
    pppc_report(File, [], Lines).

pppc_report(File, Options, Lines) :-
    decided(File, Options, Rs, _),
    findall(Line, ( member(routine(N, _, Loops, _), Rs),
                    member(Loop, Loops),
                    report_line(N, Loop, Line) ),
            Lines).

report_line(R, loop(_, L, parallel, Classes), Line) :-
    msort(Classes, Sorted),
    maplist([V-C, S]>>format(string(S), "~w:~w", [V, C]), Sorted, Ss),
    atomic_list_concat(Ss, ' ', Text),
    format(string(Line), "~w ~w parallel ~w", [R, L, Text]).
report_line(R, loop(_, L, serial(Reasons), _), Line) :-
    maplist([X, S]>>format(string(S), "~w", [X]), Reasons, Ss),
    atomic_list_concat(Ss, ' ', Text),
    format(string(Line), "~w ~w serial ~w", [R, L, Text]).
report_line(R, loop(_, L, nested(O), _), Line) :-
    format(string(Line), "~w ~w nested ~w", [R, L, O]).

%!  pppc_predict(+File, +Options, -Prediction) is det.
%
%   Prediction is prediction(Loops, Serial, Speedups) as described in
%   pppc_predict:decide/5, for threads(N) (default 4).
pppc_predict(File, Options, Prediction) :-
    decided(File, Options, _, Prediction).

                 *          PIPELINE            *
                 *******************************/

front_end(File, Typed) :-
    pppc_stage(File, parse, Tree),
    pass(semantic, check_program(Tree, Typed, Errors)),
    (   Errors == []
    ->  true
    ;   throw(pppc(semantic_errors(Errors)))
    ).

analysis(File, Routines) :-
    front_end(File, Typed),
    pass(parallelizer, analyse_program(Typed, Routines)).

decided(File, Options, Routines, Prediction) :-
    front_end(File, Typed),
    prediction_setup(Options, Table, N),
    pass(parallelizer, analyse_program(Typed, Routines0)),
    pass(predict, decide(Routines0, Table, N, Routines, Prediction)).

%   prediction_setup(+Options, -Table, -N): the cost table and number of
%   threads to predict with.
prediction_setup(Options, Table, N) :-
    option(threads(N), Options, 4),
    (   integer(N), N > 0
    ->  true
    ;   throw(pppc(bad_threads(N)))
    ),
    (   option(cost(File), Options)
    ->  true
    ;   default_cost_file(File)
    ),
    pass(cost, load_cost_table(File, Table)).

read_source(File, Codes) :-
    catch(read_file_to_codes(File, Codes, []),
          error(existence_error(source_sink, _), _),
          throw(pppc(no_source))).

%   pass(+Name, :Goal): run one compiler pass deterministically.
%   Source errors (pppc(_) exceptions) pass through; anything else is
%   an internal error of that pass.
:- meta_predicate pass(+, 0).

pass(Name, Goal) :-
    catch(Goal, E, internal_error(Name, E)),
    !.
pass(Name, _) :-
    throw(pppc(internal(Name, failed))).

internal_error(_, pppc(E)) :- !, throw(pppc(E)).
internal_error(Name, E) :- throw(pppc(internal(Name, E))).

## 8. Revisions after prototyping (2026-10-13)

The plan was written from a prototype that passed every test; these
are the points where it departs from sections 1–7.

1. **Calibration method (5).** Subtracting an empty-loop baseline from
   independent operations gave unstable tables (an out-of-order CPU
   overlaps one addition with the loop's own work, so the unit of
   measurement was a small, noisy difference). Probes now repeat their
   operation U = 4 and U = 12 times per iteration, and an operation's
   time is the difference divided by 8, which cancels the loop
   overhead. Operators are timed as dependent chains (`p_a = p_a + p_b`),
   so one integer addition is one cycle; library functions are timed
   unchained (a chain of `exp` or `ln` reaches infinity or NaN).
   Default iterations are 10^6; the output probe runs 1/64 of them.
   Two runs on the development machine agree on every entry but
   `write_item` (147 vs 149).
2. **Probes reuse codegen.** `pppc_codegen` exports `runtime_text/1`,
   and expression probes are typed tree nodes printed by `c_expr/2`, so
   calibration times the C the compiler emits.
3. **`parallelize_program/5`** (`+Typed, +Table, +N, -Parallel,
   -Routines`) replaces the planned `/4` with options: options are read
   and the table loaded once, in `pppc.pl`. `parallelize_program/3`
   remains and transforms every eligible loop without prediction (the
   Phase 1 behaviour, used by the transformation tests).
4. **End-to-end coverage (7.2).** With the shipped table, short loops in
   the Phase 1 regression programs (`names.pas`, `results.pas`,
   `features.pas`) are now serial, so their parallel code would no
   longer be compiled or run. `make check` therefore builds every
   program three ways: serial, parallel with the shipped table, and
   parallel with `test/costs/free.pl`, a table whose parallel regions
   cost nothing, so every eligible loop of two or more iterations is
   parallel as in Phase 1.
5. **Required-entry check (3.2).** The semantic pass's typing rules
   test membership (`memberchk/2`) and cannot enumerate, so the test
   runs every operator of the language over every pair of scalar types
   in both directions.
6. **The default table is recorded, not regenerated, by the plan.**
   `prolog/pppc/cost/default.pl` is the prototype's `make calibrate`
   output on the development machine (AMD Ryzen 5 5600G, gcc 16.2), so
   the `.report` files that carry `unprofitable(S, P)` times are exact.
7. **Verdict changes with the shipped table at N = 4.** Eligible loops
   that become `serial unprofitable(…)`: the one-pass vector loops of
   `cg` (lines 21, 34, 51), the final sum of `linear` (34), `mandel`

   `results`. The heavy loops (Jacobi's iteration, matrix product,
   Mandelbrot rows, n-body forces, pi, montepi) stay parallel.
8. `--dump` accepts `predict`; `tools/doc.pl` loads every module before
   documenting it (it previously relied on `library(pppc)` loading them
