# PPPC Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reproduce Gabber's Portable Parallelizing Pascal Compiler (1990) in modern SWI-Prolog, compiling TAU-Pascal to C + OpenMP, with the paper's loop classification and a passing end-to-end benchmark suite.

**Architecture:** An SWI-Prolog pack `pppc`: one module per pass (lexer, parser, semantic, label, dataflow, parloop, transform, codegen) chained in-process by `library(pppc)`, plus a `swipl pppc` command-line app. Trees use the paper's `name(Line, Args)` format, with a third Type argument after semantic analysis. Reaching definitions are computed with tabling inside `with_dataflow/4`; no other global state.

**Tech Stack:** SWI-Prolog 10.0.2 (devenv, `cachix/devenv-nixpkgs/rolling`), plunit, pldoc, gcc 16 with OpenMP, GNU make.

**Spec:** `docs/superpowers/specs/2026-10-13-pppc-phase1-design.md`

**Provenance:** every file in this plan was prototyped and run against SWI-Prolog 10.0.2 and gcc 16.2 before the plan was written. At the end, `make test` reports `All 77 (+23 sub-tests) tests passed` and `make check` passes for all 13 programs. Type the code as given; if something fails, debug it (superpowers:systematic-debugging) rather than weakening a test.

## Global Constraints

- All commands run inside `devenv shell` (or `devenv shell -- <cmd>`) from the project root; never use `/usr/bin/swipl` (9.0.4).
- SWI-Prolog version must be 10.0.2 (`swipl --version`).
- Packs are isolated: `SWIPL_PACK_PATH=$DEVENV_STATE/swipl-packs`; the project is linked there as pack `pppc`.
- Every source file is a module with an explicit export list, named `pppc_<pass>` and loaded as `library(pppc/<pass>)`.
- No `assert` crosses a module boundary; the only dynamic/tabled state is inside `pppc_dataflow:with_dataflow/4`.
- Output is generated by DCGs into code lists and written once; diagnostics go through `print_message/2` with `pppc(File, Error)` terms.
- Every pass is deterministic: tests must pass without plunit "succeeded with choicepoint" warnings.
- CLI exit status: 0 success, 1 source error, 2 internal error.
- End-to-end equality: numbers within relative tolerance 1e-9; montepi within 0.01 of π.
- Generated C must compile with `gcc -O2 -Wall -Werror -fopenmp ... -lm`.
- Commit messages end with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs the spec implies but its examples don't exercise; each is pinned by a test in the owning task:

1. **Missing or unreadable source file**: the user expects `file: cannot open source file` and exit 1, not a Prolog backtrace with exit 2. Pinned in Task 8 (`test_cli.plt: missing_file_exit_1`, `test_messages.plt: no_source`).
2. **Pascal identifiers that are C keywords or library names** (`int`, `printf`, `exp`, `main`): the user expects them to compile. Pinned in Task 7 (`var_param_and_reserved_names`) and Task 9 (`features.pas` builds with `-Werror`).
3. **Procedures, var parameters, functions and records end-to-end**: the benchmarks use none of them. Pinned in Task 9 (`features.pas`, serial == parallel output).
4. **For loops with empty ranges or bounds changed in the body**: Pascal evaluates bounds once and runs zero times when from > to. Pinned in Task 7 (`serial_for`: bound in a temporary) and Task 9 (`features.pas`: `empty loop ran 0 times`, `k = 6`).
5. **Several semantic errors in one file**: the user expects all of them reported with file:line, not just the first, and exit 1. Pinned in Task 3 (`errors_collected`) and Task 8 (`all_semantic_errors_exit_1`).

- [ ] **Step 5: Implement the lexer**

Create `prolog/pppc/lexer.pl`:

```prolog
:- module(pppc_lexer,
          [ tokenize/2                  % +Codes, -Tokens
          ]).
:- use_module(library(dcg/basics)).

/** <module> TAU-Pascal lexical analyser

Turns a list of character codes into a list of tokens of the form
tok(Line, Kind), where Kind is one of

  - kw(Keyword)    reserved word, lower case
  - id(Name)       identifier, lower case (Pascal is case-insensitive)
  - int(N)         unsigned integer literal
  - real(R)        unsigned real literal
  - str(Codes)     quoted string literal
  - punct(P)       punctuation or operator symbol, e.g. ':=', '..'
  - eof            sentinel, always the last token

The line number is threaded through the grammar as an accumulator pair.
*/

%!  tokenize(+Codes:list(code), -Tokens:list) is det.
%
%   Tokenize Codes. Throws pppc(syntax(Line, Expected, Found)) on a
%   character that cannot start a token or an unterminated comment or
%   string.

tokenize(Codes, Tokens) :-
    phrase(tokens(1, Tokens), Codes).

tokens(L0, Ts) -->
    layout(L0, L1), !,
    tokens(L1, Ts).
tokens(L, [tok(L, T)|Ts]) -->
    token(L, T), !,
    tokens(L, Ts).
tokens(L, [tok(L, eof)]) -->
    eos, !.
tokens(L, _) -->
    [C],
    { char_code(Ch, C),
      throw(pppc(syntax(L, token, char(Ch))))
    }.

%   layout(+L0, -L)// skips one unit of white space or one comment.

layout(L0, L) --> "\n", !, { L is L0 + 1 }.
layout(L, L) --> [C], { code_type(C, space) }, !.
layout(L0, L) --> "{", !, comment(`}`, L0, L0, L).
layout(L0, L) --> "(*", !, comment(`*)`, L0, L0, L).

comment(End, _, L, L) --> End, !.
comment(End, S, L0, L) --> "\n", !, { L1 is L0 + 1 }, comment(End, S, L1, L).
comment(End, S, L0, L) --> [_], !, comment(End, S, L0, L).
comment(_, S, _, _) --> eos, { throw(pppc(syntax(S, end_of_comment, eof))) }.

token(_, T) -->
    [C], { code_type(C, alpha), C \== 0'_ }, !,
    word_codes(Cs),
    { atom_codes(A0, [C|Cs]),
      downcase_atom(A0, A),
      (   keyword(A)
      ->  T = kw(A)
      ;   T = id(A)
      )
    }.
token(_, T) -->
    digit(D0), digits(Ds),
    (   fraction(Fs)
    ->  optional_exponent(Es),
        { append([[D0|Ds], `.`, Fs, Es], Cs) },
        { number_codes(R, Cs), T = real(R) }
    ;   exponent(Es)
    ->  { append([[D0|Ds], `.0`, Es], Cs), number_codes(R, Cs), T = real(R) }
    ;   { number_codes(N, [D0|Ds]), T = int(N) }
    ).
token(L, str(Cs)) -->
    "'", !, string_body(L, Cs).
token(_, punct(P)) -->
    punct(P).

word_codes([C|Cs]) --> [C], { code_type(C, csym) }, !, word_codes(Cs).
word_codes([]) --> [].

fraction([D|Ds]) --> ".", digit(D), digits(Ds).

optional_exponent(Es) --> exponent(Es), !.
optional_exponent([]) --> [].

exponent([0'e|Es]) -->
    [E], { E == 0'e ; E == 0'E }, !,
    (   [S], { S == 0'+ ; S == 0'- }
    ->  { Es = [S|Ds] }
    ;   { Es = Ds }
    ),
    digit(D), digits(Ds0),
    { Ds = [D|Ds0] }.

string_body(_, [0''|Cs]) --> "''", !, string_body(_, Cs).
string_body(_, []) --> "'", !.
string_body(L, _) --> ( "\n" ; eos ), !, { throw(pppc(syntax(L, end_of_string, eol))) }.
string_body(L, [C|Cs]) --> [C], string_body(L, Cs).

punct(P) --> [C1, C2], { atom_codes(P, [C1, C2]), punct2(P) }, !.
punct(P) --> [C], { char_code(P, C), punct1(P) }.

punct2(':=').  punct2('<=').  punct2('>=').  punct2('<>').  punct2('..').

punct1(+). punct1(-). punct1(*). punct1(/). punct1(=). punct1(<). punct1(>).
punct1('('). punct1(')'). punct1('['). punct1(']'). punct1('.'). punct1(',').
punct1(;). punct1(:).

keyword(and).      keyword(array).    keyword(begin).   keyword(const).
keyword(div).      keyword(do).       keyword(downto).  keyword(else).
keyword(end).      keyword(false).    keyword(for).     keyword(function).
keyword(if).       keyword(max).      keyword(min).     keyword(mod).
keyword(not).      keyword(of).       keyword(or).      keyword(procedure).
keyword(program).  keyword(record).   keyword(repeat).  keyword(then).
keyword(to).       keyword(true).     keyword(type).    keyword(until).
keyword(var).      keyword(while).
```

- [ ] **Step 3: Implement the parser**

Create `prolog/pppc/parser.pl`:

```prolog
:- module(pppc_parser,
          [ parse_program/2,            % +Tokens, -Tree
            parse_expression/2,         % +Tokens, -Tree
            parse_statement/2           % +Tokens, -Tree
          ]).
:- use_module(library(apply)).

/** <module> TAU-Pascal parser

A DCG over the token list produced by pppc_lexer. Builds the parse
tree in the paper's format name(Line, Args) (spec section 5.2).

Error handling: alternatives are tried only where the grammar is
genuinely ambiguous. Once a construct is recognised the parser is
committed and uses expect//1 (or must_* helpers), which throw
pppc(syntax(Line, Expected, Found)) if the next token is wrong.
*/

%!  parse_program(+Tokens, -Tree) is det.
%!  parse_expression(+Tokens, -Tree) is det.
%!  parse_statement(+Tokens, -Tree) is det.
%
%   Parse a complete token list (which ends in tok(_, eof)) as a
%   program, an expression or a single statement.  The last two exist
%   for unit testing.

parse_program(Tokens, Tree) :-
    phrase((program(Tree), expect(eof)), Tokens).
parse_expression(Tokens, Tree) :-
    phrase((expression(Tree), expect(eof)), Tokens).
parse_statement(Tokens, Tree) :-
    phrase((statement(Tree), expect(eof)), Tokens).

                 /*******************************
                 *        TOKEN HELPERS         *
                 *******************************/

kw(K, L)    --> [tok(L, kw(K))].
p(P, L)     --> [tok(L, punct(P))].
ident(N, L) --> [tok(L, id(N))].

%   line(-L)// unifies L with the line of the next token, consuming nothing.
line(L), [T] --> [T], { T = tok(L, _) }.

%   expect(+What)// consumes the expected token or throws a syntax error.
%   What is kw(K), punct P (an atom), eof, or ident(N).
expect(eof) --> [tok(_, eof)], !.
expect(kw(K)) --> kw(K, _), !.
expect(ident(N)) --> ident(N, _), !.
expect(P) --> { atom(P) }, p(P, _), !.
expect(What) --> syntax_error(What).

syntax_error(What), [tok(L, Found)] -->
    [tok(L, Found)],
    { expected_name(What, Name),
      throw(pppc(syntax(L, Name, Found)))
    }.

expected_name(kw(K), K) :- !.
expected_name(ident(_), identifier) :- !.
expected_name(X, X).

                 /*******************************
                 *     PROGRAM AND BLOCKS       *
                 *******************************/

program(program(L, [Name, Block])) -->
    ( kw(program, L) -> [] ; syntax_error(kw(program)) ),
    expect(ident(Name)), expect(;),
    block(Block),
    expect('.').

block(block(L, [Consts, Types, Vars, Procs, Body])) -->
    line(L),
    const_part(Consts),
    type_part(Types),
    var_part(Vars),
    proc_part(Procs),
    ( line(BL), kw(begin, _) -> [] ; syntax_error(kw(begin)) ),
    stmt_sequence(Stmts),
    expect(kw(end)),
    { Body = compound(BL, [Stmts]) }.

const_part(Cs) --> kw(const, _), !, const_decl(C), const_decls(Cs0), { Cs = [C|Cs0] }.
const_part([]) --> [].

const_decls([C|Cs]) --> const_decl(C), !, const_decls(Cs).
const_decls([]) --> [].

const_decl(const_decl(L, [Name, E])) -->
    ident(Name, L), expect(=), expression(E), expect(;).

type_part(Ts) --> kw(type, _), !, type_decl(T), type_decls(Ts0), { Ts = [T|Ts0] }.
type_part([]) --> [].

type_decls([T|Ts]) --> type_decl(T), !, type_decls(Ts).
type_decls([]) --> [].

type_decl(type_decl(L, [Name, T])) -->
    ident(Name, L), expect(=), type_expr(T), expect(;).

var_part(Vs) --> kw(var, _), !, var_decl(V), var_decls(Vs0), { Vs = [V|Vs0] }.
var_part([]) --> [].

var_decls([V|Vs]) --> var_decl(V), !, var_decls(Vs).
var_decls([]) --> [].

var_decl(var_decl(L, [Names, T])) -->
    ident_list(Names, L), expect(:), type_expr(T), expect(;).

ident_list([N|Ns], L) --> ident(N, L), ident_list_rest(Ns).
ident_list_rest([N|Ns]) --> p(',', _), !, expect(ident(N)), ident_list_rest(Ns).
ident_list_rest([]) --> [].

proc_part([P|Ps]) --> proc_decl(P), !, proc_part(Ps).
proc_part([]) --> [].

                 *          STATEMENTS          *
                 *******************************/

    kw(begin, L), !, stmt_sequence(Ss), expect(kw(end)).

    kw(if, L), !, expression(C), expect(kw(then)), statement(Then),
    (   kw(else, _)
    ->  statement(Else)
    ;   line(EL), { Else = empty(EL, []) }
    ).

    kw(for, L), !,
    line(VL), expect(ident(V)), { Var = id(VL, [V]) },
    expect(':='), expression(From),
    (   kw(to, _) -> { Dir = up }
    ;   kw(downto, _) -> { Dir = down }
    ;   syntax_error(kw(to))
    ),
    expression(To), expect(kw(do)), statement(Body).

    kw(while, L), !, expression(C), expect(kw(do)), statement(Body).

    ;   { memberchk(Name, [write, writeln]) }

          S = write(L, [NL, Args]) }
    ;   optional_args(Args),
        { S = pcall(L, [Name, Args]) }
    ).

    line(L).

    { Args = [A|As] }.
optional_args([]) --> [].

expr_list_rest([]) --> [].

    p('[', L), !, expression(I), expr_list_rest(Is), expect(']'),
    selectors(index(L, [Base, [I|Is]]), Var).
selectors(Base, Var) -->
    p('.', L), [tok(_, id(F))], !,
    selectors(field(L, [Base, F]), Var).
selectors(Var, Var) --> [].

                 /*******************************
                 *          EXPRESSIONS         *
                 *******************************/

%   Precedence, lowest first:
%     relational  = <> < <= > >=  min max   (non-associative ... left here)
%     additive    + - or
%     multiplicative * / div mod and
%     unary       not, sign
%
%   Left-associative levels are parsed iteratively to avoid left recursion.

expression(E) -->
    simple_expression(L0),
    relational_rest(L0, E).

relational_rest(L0, E) -->
    rel_op(Op, L), !, simple_expression(R),
    relational_rest(op2(L, [Op, L0, R]), E).
relational_rest(E, E) --> [].

simple_expression(E) -->
    (   p(-, L)
    ->  term(T0), { T1 = op1(L, [-, T0]) }
    ;   p(+, _)
    ->  term(T1)
    ;   term(T1)
    ),
    additive_rest(T1, E).

additive_rest(L0, E) -->
    add_op(Op, L), !, term(R),
    additive_rest(op2(L, [Op, L0, R]), E).
additive_rest(E, E) --> [].

term(E) -->
    factor(F0),
    multiplicative_rest(F0, E).

multiplicative_rest(L0, E) -->
    mul_op(Op, L), !, factor(R),
    multiplicative_rest(op2(L, [Op, L0, R]), E).
multiplicative_rest(E, E) --> [].

factor(iconst(L, [N]))  --> [tok(L, int(N))], !.
factor(fconst(L, [R]))  --> [tok(L, real(R))], !.
factor(string(L, [Cs])) --> [tok(L, str(Cs))], !.
factor(bconst(L, [true]))  --> kw(true, L), !.
factor(bconst(L, [false])) --> kw(false, L), !.
factor(op1(L, [not, F])) --> kw(not, L), !, factor(F).
factor(E) --> p('(', _), !, expression(E), expect(')').
factor(E) -->
    ident(Name, L), !,
    (   p('(', _)
    ->  expression(A), expr_list_rest(As), expect(')'),
        { E = fcall(L, [Name, [A|As]]) }
    ;   selectors(id(L, [Name]), E)
    ).
factor(_) --> syntax_error(expression).

rel_op(Op, L) --> p(P, L), { rel_punct(P, Op) }, !.
rel_op(min, L) --> kw(min, L).
rel_op(max, L) --> kw(max, L).

rel_punct(=, =). rel_punct('<>', '<>'). rel_punct(<, <).
rel_punct('<=', '<='). rel_punct(>, >). rel_punct('>=', '>=').

add_op(+, L)  --> p(+, L).
add_op(-, L)  --> p(-, L).
add_op(or, L) --> kw(or, L).

mul_op(*, L)   --> p(*, L).
mul_op(/, L)   --> p(/, L).
mul_op(div, L) --> kw(div, L).
mul_op(mod, L) --> kw(mod, L).
mul_op(and, L) --> kw(and, L).
```

```prolog
:- module(pppc_semantic,
          [ check_program/3             % +Tree, -Typed, -Errors
          ]).
:- use_module(library(assoc)).
:- use_module(library(apply)).
:- use_module(library(lists)).

/** <module> TAU-Pascal semantic analysis

Builds the symbol table and produces the typed parse tree (spec
section 5.3). Every node gains a third argument holding its type;
statements have type `void`.

The checker is written as a DCG whose "string" is the list of errors
found: a check that finds a problem emits pppc(semantic(Line, Msg))
with report//2 and carries on, giving the offending node type `error`.
Operations on `error` operands are silently accepted, so one mistake
produces one message rather than a cascade.

Normalised types:

    integer | real | boolean | string | void | error
    array(Lo, Hi, Elem)            one dimension; a[1..n,1..m] nests
    record([Field-Type, ...])

Constants are replaced by their values; references to var parameters
become vparam/3 nodes; assignment to a function's own name becomes
fresult/3; integer-to-real widening is an explicit itor/3 node;
calls to standard functions are builtin/3 nodes, to user routines
fcall/3 or pcall/3, with var arguments wrapped in addr/3.
*/

%!  check_program(+Tree, -Typed, -Errors:list) is det.
%
%   Type check a parse tree. Errors is the list of
%   pppc(semantic(Line, Msg)) terms found, in source order; Typed is
%   only meaningful if Errors is [].

check_program(Tree, Typed, Errors) :-
    phrase(program(Tree, Typed), Errors).

report(L, Msg) --> [pppc(semantic(L, Msg))].

                 /*******************************
                 *        ENVIRONMENT           *
                 *******************************/

%   The environment is env(Scopes, Routine). Scopes is a list of
%   assocs from name to entry, innermost first: [Globals, Predefined]
%   in the main program, [Locals, Globals, Predefined] inside a
%   routine. Routine is `main`, proc(Name) or func(Name, ResultType),
%   naming the routine whose body is being checked.
%
%   Entries: var(T), vparam(T), const(T, V), type(T), proc(Params, R)
%   where Params is a list of p(Mode, T) and R is a type or `none`.

initial_env(env([Globals, Predefined], main)) :-
    empty_assoc(Globals),
    list_to_assoc([ integer-type(integer),
                    real-type(real),
                    boolean-type(boolean)
                  ], Predefined).

enter_routine(Routine, env(Scopes, _), env([Locals|Scopes], Routine)) :-
    empty_assoc(Locals).

lookup(Name, env(Scopes, _), Entry) :-
    member(Scope, Scopes),
    get_assoc(Name, Scope, Entry),
    !.

%   declare(+Line, +Name, +Entry, +Env0, -Env)// adds Name to the
%   innermost scope, reporting a redeclaration within that scope.

declare(L, Name, Entry, env([S0|Ss], R), env([S|Ss], R)) -->
    (   { get_assoc(Name, S0, _) }
    ->  report(L, redeclared(Name)), { S = S0 }
    ;   { put_assoc(Name, S0, Entry, S) }
    ).

                 /*******************************
                 *      PROGRAM & BLOCKS        *
                 *******************************/

program(program(L, [Name, Block]), program(L, [Name, TBlock], void)) -->
    { initial_env(Env0) },
    block(Block, Env0, TBlock).

block(block(L, [Consts, Types, Vars, Procs, Body]), Env0,
      block(L, [TVars, TProcs, TBody], void)) -->
    consts(Consts, Env0, Env1),
    types(Types, Env1, Env2),
    vars(Vars, Env2, Env3, TVars),
    proc_headers(Procs, Env3, Env4),
    proc_bodies(Procs, Env4, TProcs),
    stmt(Body, Env4, TBody).

consts([], Env, Env) --> [].
consts([const_decl(L, [Name, E])|Cs], Env0, Env) -->
    (   { const_value(E, Env0, T, V) }
    ->  declare(L, Name, const(T, V), Env0, Env1)
    ;   report(L, not_constant(Name)), { Env1 = Env0 }
    ),
    consts(Cs, Env1, Env).

types([], Env, Env) --> [].
types([type_decl(L, [Name, TE])|Ts], Env0, Env) -->
    type_expr(TE, Env0, T),
    declare(L, Name, type(T), Env0, Env1),
    types(Ts, Env1, Env).

vars([], Env, Env, []) --> [].
vars([var_decl(L, [Names, TE])|Vs], Env0, Env, [var_decl(L, [Names, T], void)|TVs]) -->
    type_expr(TE, Env0, T),
    declare_all(Names, L, var(T), Env0, Env1),
    vars(Vs, Env1, Env, TVs).

declare_all([], _, _, Env, Env) --> [].
declare_all([N|Ns], L, Entry, Env0, Env) -->
    declare(L, N, Entry, Env0, Env1),
    declare_all(Ns, L, Entry, Env1, Env).

                 /*******************************
                 *          CONSTANTS           *
                 *******************************/

%!  const_value(+Expr, +Env, -Type, -Value) is semidet.
%
%   Evaluate a constant expression at compile time.

const_value(iconst(_, [N]), _, integer, N).
const_value(fconst(_, [R]), _, real, R).
const_value(bconst(_, [B]), _, boolean, B).
const_value(id(_, [N]), Env, T, V) :-
    lookup(N, Env, const(T, V)).
const_value(op1(_, [-, E]), Env, T, V) :-
    const_value(E, Env, T, V0),
    memberchk(T, [integer, real]),
    V is -V0.
const_value(op2(_, [Op, A, B]), Env, T, V) :-
    const_value(A, Env, TA, VA),
    const_value(B, Env, TB, VB),
    const_op(Op, TA, TB, VA, VB, T, V).

const_op(+, integer, integer, A, B, integer, V) :- V is A + B.
const_op(-, integer, integer, A, B, integer, V) :- V is A - B.
const_op(*, integer, integer, A, B, integer, V) :- V is A * B.
const_op(div, integer, integer, A, B, integer, V) :- B =\= 0, V is A // B.
const_op(Op, TA, TB, A, B, real, V) :-
    memberchk(Op, [+, -, *, /]),
    memberchk(TA, [integer, real]), memberchk(TB, [integer, real]),
    ( TA == real ; TB == real ; Op == / ),
    F =.. [Op, A, B],
    V is float(F).

                 /*******************************
                 *            TYPES             *
                 *******************************/

type_expr(tname(L, [N]), Env, T) -->
    (   { lookup(N, Env, type(T0)) }
    ->  { T = T0 }
    ;   report(L, not_a_type(N)), { T = error }
    ).
type_expr(subrange(L, [Lo, Hi]), Env, T) -->
    bounds(L, Lo, Hi, Env, _, _),
    { T = integer }.
type_expr(array(L, [Ranges, ElemE]), Env, T) -->
    type_expr(ElemE, Env, Elem),
    array_type(Ranges, L, Elem, Env, T).
type_expr(record(_, [FieldDecls]), Env, record(Fields)) -->
    field_decls(FieldDecls, Env, Fields).

array_type([], _, Elem, _, Elem) --> [].
array_type([subrange(SL, [LoE, HiE])|Rs], L, Elem, Env, T) -->
    bounds(SL, LoE, HiE, Env, Lo, Hi),
    array_type(Rs, L, Elem, Env, Inner),
    { T = array(Lo, Hi, Inner) }.

bounds(L, LoE, HiE, Env, Lo, Hi) -->
    (   { const_value(LoE, Env, integer, Lo),
          const_value(HiE, Env, integer, Hi),
          Lo =< Hi }
    ->  []
    ;   report(L, bad_bounds), { Lo = 1, Hi = 1 }
    ).

field_decls([], _, []) --> [].
field_decls([field_decl(_, [Names, TE])|Ds], Env, Fields) -->
    type_expr(TE, Env, T),
    { findall(N-T, member(N, Names), Fs1) },
    field_decls(Ds, Env, Fs2),
    { append(Fs1, Fs2, Fields) }.

numeric(integer).
numeric(real).

%   all_numeric(+Type): every leaf of the compound type is numeric.
all_numeric(array(_, _, E)) :- all_numeric(E).
all_numeric(record(Fs)) :- forall(member(_-T, Fs), all_numeric(T)).
all_numeric(T) :- numeric(T).

compound_type(array(_, _, _)).
compound_type(record(_)).

                 /*******************************
                 *          ROUTINES            *
                 *******************************/

proc_headers([], Env, Env) --> [].
```

```prolog
:- module(pppc_label,
          [ label_body/2,               % +Compound, -Labelled
            unlabel_body/3              % +Labelled, +Line, -Compound
          ]).
:- use_module(library(apply)).
:- use_module(library(lists)).

/** <module> Statement labelling

Gives every statement of a routine body a hierarchical label, a list
of integers, as in the paper (section 4.4.6). The statements directly
in a sequence are numbered 1, 2, ... after the label of the enclosing
structured statement, so a statement's label is a prefix of the labels
of every statement nested inside it.

  - The routine body's statements are [1], [2], ...
  - The body of for/while/repeat with label P is labelled [P,1], [P,2], ...
    A begin..end body is transparent: its statements are the children.
  - The then and else branches of an `if` P are [P,1] and [P,2]. A
    begin..end branch is itself a node; its statements are [P,1,1], ...
  - Nested begin..end inside a sequence is flattened into it.
  - Empty statements inside sequences are dropped.

Labelled statements are lbl(Label, Stmt). In a labelled for/while
statement the body argument is a list of lbl/2 terms; in a repeat the
statement list is; in an if each branch is a single lbl/2 term.
*/

%!  label_body(+Body, -Labelled:list) is det.
%
%   Body is a typed compound/3 statement (a routine body).
label_body(compound(_, [Ss], _), LSs) :-
    label_seq(Ss, [], 1, LSs).

label_seq([], _, _, []).
label_seq([compound(_, [Inner], _)|Ss], P, K, LSs) :- !,
    append(Inner, Ss, All),
    label_seq(All, P, K, LSs).
label_seq([empty(_, _, _)|Ss], P, K, LSs) :- !,
    label_seq(Ss, P, K, LSs).
label_seq([S|Ss], P, K0, [LS|LSs]) :-
    append(P, [K0], Lab),
    label_stmt(S, Lab, LS),
    K is K0 + 1,
    label_seq(Ss, P, K, LSs).

label_stmt(for(L, [V, F, T, D, Body], Ty), P, lbl(P, for(L, [V, F, T, D, LB], Ty))) :- !,
    body_list(Body, Ss), label_seq(Ss, P, 1, LB).
label_stmt(while(L, [C, Body], Ty), P, lbl(P, while(L, [C, LB], Ty))) :- !,
    body_list(Body, Ss), label_seq(Ss, P, 1, LB).
label_stmt(repeat(L, [Ss, C], Ty), P, lbl(P, repeat(L, [LB, C], Ty))) :- !,
    label_seq(Ss, P, 1, LB).
label_stmt(if(L, [C, Then, Else], Ty), P, lbl(P, if(L, [C, LT, LE], Ty))) :- !,
    append(P, [1], PT), label_branch(Then, PT, LT),
    append(P, [2], PE), label_branch(Else, PE, LE).
label_stmt(S, P, lbl(P, S)).

label_branch(compound(L, [Ss], Ty), P, lbl(P, compound(L, [LSs], Ty))) :- !,
    label_seq(Ss, P, 1, LSs).
label_branch(S, P, LS) :-
    label_stmt(S, P, LS).

body_list(compound(_, [Ss], _), Ss) :- !.
body_list(S, [S]).

%!  unlabel_body(+Labelled:list, +Line, -Body) is det.
%
%   Inverse of label_body/2 (up to the flattening it performs). Also
%   used by later passes, which may have replaced statements inside
%   lbl/2 wrappers.
unlabel_body(LSs, L, compound(L, [Ss], void)) :-
    maplist(unlabel, LSs, Ss).

unlabel(lbl(_, S), U) :- unlabel_stmt(S, U).

unlabel_stmt(for(L, [V, F, T, D, LB], Ty), for(L, [V, F, T, D, B], Ty)) :- !,
    unlabel_body(LB, L, B).
unlabel_stmt(omp_for(L, [V, F, T, D, LB, Cl], Ty), omp_for(L, [V, F, T, D, B, Cl], Ty)) :- !,
    unlabel_body(LB, L, B).
unlabel_stmt(while(L, [C, LB], Ty), while(L, [C, B], Ty)) :- !,
    unlabel_body(LB, L, B).
unlabel_stmt(repeat(L, [LB, C], Ty), repeat(L, [Ss, C], Ty)) :- !,
    maplist(unlabel, LB, Ss).
unlabel_stmt(if(L, [C, LT, LE], Ty), if(L, [C, T, E], Ty)) :- !,
    unlabel(LT, T), unlabel(LE, E).
unlabel_stmt(compound(L, [LSs], Ty), compound(L, [Ss], Ty)) :- !,
    maplist(unlabel, LSs, Ss).
unlabel_stmt(S, S).
```

```prolog
:- module(pppc_dataflow,

/** <module> Reaching definitions

Builds a statement-level control flow graph for one routine body
(labelled by pppc_label) as dynamic facts, and computes reaching
definitions over it with tabling. This replaces the paper's explicit
iterative solution of the dataflow equations (ASU86 10.5).

The graph has one node per labelled statement plus two extra nodes:

  - [-1], the routine entry, which defines every variable;
  - [0], the routine exit, which uses the variables whose values
    escape the routine (globals, var parameters, function result).

Facts (local to this module, valid only inside with_dataflow/4):

  - def(Label, Var, Kind)  Kind is `kill` for an assignment to the
    whole variable, `nokill` for an element/field assignment or a
    possible modification by a call;
  - use(Label, Var);
  - edge(From, To).
*/

:- meta_predicate with_dataflow(+, +, +, 0).

:- dynamic def/3, use/2, edge/2.

:- table reach_in/3, clear/3.

%!  with_dataflow(+Labelled:list, +AllVars:list, +ExitVars:list, :Goal)
%
%   Run Goal with the dataflow facts for the routine body Labelled
%   loaded. AllVars are all variables visible in the routine; ExitVars
%   those live at its exit. Goal is run as once/1.
with_dataflow(LSs, AllVars, ExitVars, Goal) :-
    setup_call_cleanup(
        load_graph(LSs, AllVars, ExitVars),
        once(Goal),
        clear_graph).

clear_graph :-
    retractall(def(_, _, _)),
    retractall(use(_, _)),
    retractall(edge(_, _)),
    abolish_module_tables(pppc_dataflow).

load_graph(LSs, AllVars, ExitVars) :-
    clear_graph,
    forall(member(V, AllVars), assertz(def([-1], V, kill))),
    forall(member(V, ExitVars), assertz(use([0], V))),
    flow_seq(LSs, AllVars, [[-1]], Exits),
    connect(Exits, [0]).

                 /*******************************
                 *        CONTROL FLOW          *
                 *******************************/

%   flow_seq(+Stmts, +AllVars, +Preds, -Exits): Preds are the nodes
%   that flow into the first statement; Exits those that flow out of
%   the last.

flow_seq([], _, Preds, Preds).
flow_seq([S|Ss], Vs, Preds, Exits) :-
    flow(S, Vs, Preds, X),
    flow_seq(Ss, Vs, X, Exits).

flow(lbl(P, repeat(_, [Body, C], _)), Vs, Preds, [P]) :- !,
    node_effects(P, C, Vs),
    flow_seq(Body, Vs, [P|Preds], X),
    connect(X, P).
flow(lbl(P, S), Vs, Preds, Exits) :-
    connect(Preds, P),
    stmt_effects(S, P, Vs),
    flow_inner(S, P, Vs, Exits).

flow_inner(for(_, [_, _, _, _, Body], _), P, Vs, [P]) :- !,
    flow_seq(Body, Vs, [P], X), connect(X, P).
flow_inner(omp_for(_, [_, _, _, _, Body, _], _), P, Vs, [P]) :- !,
    flow_seq(Body, Vs, [P], X), connect(X, P).
flow_inner(while(_, [_, Body], _), P, Vs, [P]) :- !,
    flow_seq(Body, Vs, [P], X), connect(X, P).
flow_inner(if(_, [_, Then, Else], _), P, Vs, Exits) :- !,
    flow(Then, Vs, [P], X1),
    flow(Else, Vs, [P], X2),
    append(X1, X2, Exits).
flow_inner(compound(_, [LSs], _), P, Vs, Exits) :- !,
    flow_seq(LSs, Vs, [P], Exits).
flow_inner(_, P, _, [P]).

connect(Preds, N) :-
    forall(member(P, Preds), assertz(edge(P, N))).

                 /*******************************
                 *      DEFINITIONS & USES      *
                 *******************************/

%   stmt_effects(+Stmt, +Label, +AllVars) asserts the def/use facts of
%   the statement node itself (not of nested statements).

stmt_effects(S, P, Vs) :-
    shallow_part(S, Part),
    has_user_call(Part), !,
    call_effects(P, Vs).
stmt_effects(assign(_, [T, E], _), P, _) :- !,
    target_base(T, V, Whole),
    target_uses(T, U1), expr_vars(E, U2), ord_union(U1, U2, Us),
    add_uses(P, Us),
    add_def(P, V, Whole).
stmt_effects(zero_assign(_, [T], _), P, _) :- !,
    target_base(T, V, Whole),
    target_uses(T, Us),
    add_uses(P, Us),
    add_def(P, V, Whole).
stmt_effects(S, P, _) :-
    ( S = for(_, [Var, F, T, _, _], _) ; S = omp_for(_, [Var, F, T, _, _, _], _) ), !,
    expr_vars(F-T, Us),
    add_uses(P, Us),
    var_node(Var, V),
    add_def(P, V, true).
stmt_effects(S, P, Vs) :-
    node_effects(P, S, Vs).

%   node_effects(+Label, +Term, +AllVars): Term (a condition or a whole
%   simple statement) is only read.
node_effects(P, Term, Vs) :-
    (   has_user_call(Term)
    ->  call_effects(P, Vs)
    ;   shallow_part(Term, Part),
        expr_vars(Part, Us),
        add_uses(P, Us)
    ).

%   shallow_part(+Stmt, -Part): the parts of Stmt evaluated at its own
%   node, excluding nested statements.
shallow_part(for(_, [V, F, T, _, _], _), V-F-T) :- !.
shallow_part(omp_for(_, [V, F, T, _, _, _], _), V-F-T) :- !.
shallow_part(while(_, [C, _], _), C) :- !.
shallow_part(if(_, [C, _, _], _), C) :- !.
shallow_part(compound(_, _, _), none) :- !.
shallow_part(S, S).

%   A user call may read and modify any visible variable.
call_effects(P, Vs) :-
    add_uses(P, Vs),
    forall(member(V, Vs), add_def(P, V, false)).

add_uses(P, Us) :-
    forall(member(U, Us), assertz(use(P, U))).

add_def(P, V, true)  :- assertz(def(P, V, kill)).
add_def(P, V, false) :- assertz(def(P, V, nokill)).

                 /*******************************
                 *     REACHING DEFINITIONS     *
                 *******************************/

%!  reach(?Var, ?Def, ?Use) is nondet.
%
%   The value of Var assigned at statement Def may be read at
%   statement Use. Corresponds to the paper's reach/3 facts.
reach(V, S, U) :-
    use(U, V),
    reach_in(V, S, U).

%!  defines(?Label, ?Var, ?Kind) is nondet.
defines(P, V, K) :- def(P, V, K).

%   reach_in(V, S, N): the definition of V at S reaches the entry of N.
reach_in(V, S, N) :-
    edge(P, N),
    reach_out(V, S, P).

reach_out(V, P, P) :-
    def(P, V, _).
reach_out(V, S, P) :-
    reach_in(V, S, P),
    \+ def(P, V, kill).

%!  inside(+Loop, +Label) is semidet.
%
%   Label is strictly inside the statement labelled Loop.
inside(L, S) :-
    append(L, [_|_], S).

%!  carried(+Loop, +Var, -Use) is semidet.
%
%   A value of Var assigned inside Loop survives to the loop header
%   (through the back edge, or around an enclosing loop) and is then
%   read at Use inside Loop before being reassigned: a loop-carried
%   flow dependence.
carried(L, V, U) :-
    use(U, V),
    inside(L, U),
    reach_in(V, S, L),
    inside(L, S),
    \+ def(L, V, kill),
    clear(V, L, U),
    !.

%   clear(V, N, M): there is a path from the exit of N to the entry of
%   M on which no node kills V.
clear(_, N, M) :-
    edge(N, M).
clear(V, N, M) :-
    edge(N, P),
    \+ def(P, V, kill),
    clear(V, P, M).
```

```prolog
/** <module> Parallel loop detection

Implements the parallelization rules of the paper (section 4.3.3).
Must be called inside pppc_dataflow:with_dataflow/4 for the routine.

A bottom-up traversal computes for each statement an access summary

    acc(Refs, Changes, Assoc, Arrays, Effects)

  - Refs, Changes: ordsets of variables read / written;
  - Assoc: ordset of Var-Op for variables only updated by statements
    `Var := Var Op Expr`, Op in + * and or min max;
  - Arrays: list of Array-Access, Access is sub(FirstSubscript) or
    `whole`;
  - Effects: ordset of call, io, vparam_change.

Summaries of compound statements are merged as described in section
4.4.6: an associative variable stays associative only if no other
part of the statement touches it, or uses a different operator.

A `for` loop is parallel if it has no effects and every variable it
touches is one of index, read_only, associative(Op), distributed or
local. Only the outermost parallel loop is taken; loops inside it are
reported as nested.
*/

%!  classify_loops(+Labelled:list, -Loops:list) is det.
%
%   Loops has an entry loop(Label, Line, Verdict, Classes) for each
%   for loop, in source order. Verdict is `parallel`, serial(Reasons)
%   or nested(OuterLine). Classes is a list of Var-Class (empty for
%   nested loops).
classify_loops(LSs, Loops) :-
    phrase(loops_seq(LSs), Loops).

loops_seq([]) --> [].
loops_seq([S|Ss]) --> loops(S), loops_seq(Ss).

loops(lbl(P, for(L, [Var, _, _, _, Body], _))) --> !,
    { classify(P, Var, Body, Verdict, Classes) },
    [loop(P, L, Verdict, Classes)],
    (   { Verdict == parallel }
    ->  nested(Body, L)
    ;   loops_seq(Body)
    ).
loops(lbl(_, while(_, [_, Body], _)))  --> !, loops_seq(Body).
loops(lbl(_, repeat(_, [Body, _], _))) --> !, loops_seq(Body).
loops(lbl(_, if(_, [_, T, E], _)))     --> !, loops(T), loops(E).
loops(lbl(_, compound(_, [Ss], _)))    --> !, loops_seq(Ss).
loops(_) --> [].

nested(Stmts, Outer) -->
    { findall(loop(P, L, nested(Outer), []),
              ( member(S, Stmts), sub_term(lbl(P, for(L, _, _)), S) ),
              Inner) },
    Inner.

                 /*******************************
                 *        CLASSIFICATION        *
                 *******************************/

classify(P, Var, Body, Verdict, Classes) :-
    var_node(Var, I),
    seq_access(Body, acc(Refs, Chgs, Assoc, Arrays, Effects)),
    pairs_keys(Assoc, AssocVars),
    pairs_keys(Arrays, ArrayVars0),
    sort(ArrayVars0, ArrayVars),
    foldl(ord_union, [Refs, Chgs, AssocVars, ArrayVars], [I], All),
    maplist(var_class(P, I, Chgs, Assoc, Arrays), All, Classes),
    findall(dependent(V), member(V-dependent, Classes), Deps),
    append(Effects, Deps, Reasons),
    (   Reasons == []
    ->  Verdict = parallel
    ;   Verdict = serial(Reasons)
    ).

var_class(P, I, Chgs, Assoc, Arrays, V, V-Class) :-
    (   V == I
    ->  ( ord_memberchk(V, Chgs) -> Class = dependent ; Class = index )
    ;   memberchk(V-Op, Assoc)
    ->  Class = associative(Op)
    ;   \+ ord_memberchk(V, Chgs)
    ->  Class = read_only
    ;   distributed(V, I, Arrays)
    ->  Class = distributed
    ;   is_local(V, P)
    ->  Class = local
    ;   Class = dependent
    ).

%   Every access of array V is subscripted, in its first dimension, by
%   the loop index I itself.
distributed(V, I, Arrays) :-
    memberchk(V-_, Arrays),
    forall(member(V-Access, Arrays),
           ( Access = sub(Sub), var_node(Sub, I) )).

%!  is_local(+Var, +Loop) is semidet.
%
%   Var is local to the loop labelled Loop: it is only assigned as a
%   whole, and its value is never passed between iterations or into
%   or out of the loop. Written after the
%   paper's is_local/2, with the "previous iteration" test done
%   exactly by pppc_dataflow:carried/3 instead of the before/2
%   ordering of labels.
is_local(V, L) :-
    set_inside(V, L),
    \+ partly_set_inside(V, L),
    \+ value_enters(V, L),
    \+ value_escapes(V, L),
    \+ carried(L, V, _).

set_inside(V, L) :-
    defines(S, V, _), inside(L, S), !.

%   An element or field assignment cannot make a private copy whole.
partly_set_inside(V, L) :-
    defines(S, V, nokill), inside(L, S), !.

value_enters(V, L) :-
    reach(V, S, U), inside(L, U), \+ inside(L, S), !.

value_escapes(V, L) :-
    reach(V, S, U), inside(L, S), \+ inside(L, U), !.

                 /*******************************
                 *        ACCESS SUMMARY        *
                 *******************************/

%!  stmt_access(+Stmt, -Access) is det.
%
%   Stmt may be labelled (lbl/2) or not.
stmt_access(lbl(_, S), A) :- !,
    stmt_access(S, A).
stmt_access(S, A) :-
    shallow_access(S, A0),
    findall(C, child_stmt(S, C), Children),
    seq_access(Children, A1),
    merge_access(A0, A1, A).

seq_access(Ss, A) :-
    empty_access(A0),
    foldl(merge_stmt, Ss, A0, A).

merge_stmt(S, A0, A) :-
    stmt_access(S, A1),
    merge_access(A0, A1, A).

empty_access(acc([], [], [], [], [])).

child_stmt(for(_, [_, _, _, _, B], _), S) :- member(S, B).
child_stmt(while(_, [_, B], _), S) :- member(S, B).
child_stmt(repeat(_, [B, _], _), S) :- member(S, B).
child_stmt(if(_, [_, T, E], _), S) :- member(S, [T, E]).
child_stmt(compound(_, [B], _), S) :- member(S, B).

%   shallow_access(+Stmt, -Access): what the statement's own node does.
shallow_access(assign(_, [T, E], _), A) :-
    assoc_update(T, E, V, Op, Other), !,
    expr_vars(Other, Refs),
    arrays_in(Other, Arrays),
    effects_of(assign(_, [T, E], _), Effects),
    A = acc(Refs, [], [V-Op], Arrays, Effects).
shallow_access(S, acc(Refs, Chgs, [], Arrays, Effects)) :-
    reads_writes(S, Refs, Chgs),
    arrays_in(S, Arrays),
    effects_of(S, Effects).

assoc_update(T, op2(_, [Op, X, Y], _), V, Op, Other) :-
    var_node(T, V),
    arg(3, T, Type), memberchk(Type, [integer, real, boolean]),
    memberchk(Op, [+, *, and, or, min, max]),
    (   var_node(X, V), expr_vars(Y, YVs), \+ ord_memberchk(V, YVs)
    ->  Other = Y
    ;   var_node(Y, V), expr_vars(X, XVs), \+ ord_memberchk(V, XVs)
    ->  Other = X
    ).

reads_writes(assign(_, [T, E], _), Refs, [V]) :- !,
    target_base(T, V, _),
    target_uses(T, U1), expr_vars(E, U2), ord_union(U1, U2, Refs).
reads_writes(zero_assign(_, [T], _), Refs, [V]) :- !,
    target_base(T, V, _), target_uses(T, Refs).
reads_writes(for(_, [Var, F, T, _, _], _), Refs, [I]) :- !,
    var_node(Var, I), expr_vars(F-T, Refs).
reads_writes(pcall(_, [_, Args], _), Refs, Chgs) :- !,
    expr_vars(Args, Refs),
    findall(V, (member(addr(_, [X], _), Args), target_base(X, V, _)), Vs),
    sort(Vs, Chgs).
reads_writes(S, Refs, []) :-
    shallow_expr(S, E), expr_vars(E, Refs).

shallow_expr(while(_, [C, _], _), C) :- !.
shallow_expr(repeat(_, [_, C], _), C) :- !.
shallow_expr(if(_, [C, _, _], _), C) :- !.
shallow_expr(compound(_, _, _), none) :- !.
shallow_expr(S, S).

%   arrays_in(+Term, -Accesses): array accesses in the expressions of
%   the statement node (not nested statements).
arrays_in(S, As) :-
    shallow_terms(S, T),
    phrase(arrays(T), As).

shallow_terms(for(_, [V, F, T, _, _], _), V-F-T) :- !.
shallow_terms(S, E) :- shallow_expr(S, E).

arrays(index(_, [A, I], _)) --> { var_node(A, N) }, !, [N-sub(I)], arrays(I).
arrays(N) --> { var_node(N, V), arg(3, N, array(_, _, _)) }, !, [V-whole].
arrays(T) --> { compound(T), \+ var_node(T, _) }, !,
    { T =.. [_|Args] }, arrays_list(Args).
arrays(_) --> [].

arrays_list([]) --> [].
arrays_list([A|As]) --> arrays(A), arrays_list(As).

effects_of(S, Effects) :-
    findall(E, effect(S, E), Es),
    sort(Es, Effects).

effect(S, call) :- shallow_terms(S, T), has_user_call(T).
effect(write(_, _, _), io).
effect(S, vparam_change) :-
    ( S = assign(_, [T, _], _) ; S = zero_assign(_, [T], _) ),
    sub_term(B, T), compound(B), B = vparam(_, _, _), !.

%!  merge_access(+A1, +A2, -A) is det.
merge_access(acc(R1, C1, A1, Ar1, E1), acc(R2, C2, A2, Ar2, E2), acc(R, C, A, Ar, E)) :-
    ord_union(R1, C1, T1),
    ord_union(R2, C2, T2),
    keep_assoc(A1, T2, A2, K1, D1),
    keep_assoc(A2, T1, A1, K2, D2),
    ord_union(K1, K2, A),
    ord_union(D1, D2, Dropped),
    foldl(ord_union, [R1, R2, Dropped], [], R),
    foldl(ord_union, [C1, C2, Dropped], [], C),
    append(Ar1, Ar2, Ar),
    ord_union(E1, E2, E).

%   keep_assoc(+Assoc, +OtherTouched, +OtherAssoc, -Kept, -Dropped)
keep_assoc([], _, _, [], []).
keep_assoc([V-Op|As], Touched, Other, Kept, Dropped) :-
    (   \+ ord_memberchk(V, Touched),
        ( memberchk(V-Op2, Other) -> Op2 == Op ; true )
    ->  Kept = [V-Op|Kept1], Dropped = Dropped1
    ;   Kept = Kept1, Dropped = [V|Dropped1]
    ),
    keep_assoc(As, Touched, Other, Kept1, Dropped1).
```

```prolog
          [ analyse_program/2,          % +Typed, -Routines

          ]).

:- use_module(library(pppc/dataflow)).

/** <module> Parallelizer driver and loop transformation

Runs the parallelizer phases of the paper (section 4.4.6) over each
routine of a typed program: statement labelling, reaching definitions,
parallel loop detection, code transformation and cleanup. Run time
prediction is Phase 2; every loop found parallel is transformed.

A parallel loop becomes

    omp_for(Line, [Var, From, To, Dir, Body, Clauses], void)

where Clauses is a list of private(Vars), shared(Vars) and
reduction(Op, Vars) terms with non-empty variable lists.
*/

%!  analyse_program(+Typed, -Routines:list) is det.
%
%   Routines has one routine(Name, Labelled, Loops, Reach) per routine
%   (the main program first, named `main`). Reach is the sorted list of
%   reach(Var, Def, Use) facts. Used for --dump and --report.
analyse_program(Typed, Routines) :-
    program_routines(Typed, Rs),
    maplist(analyse_routine, Rs, Routines).

%!  parallelize_program(+Typed, -Parallel, -Routines) is det.
parallelize_program(Typed, Parallel, Routines) :-
    analyse_program(Typed, Routines),
    Typed = program(L, [Name, block(BL, [Decls, Procs, Body], void)], void),
    routine_body(main, Routines, Body, NewBody),
    maplist(transform_proc(Routines), Procs, NewProcs),
    Parallel = program(L, [Name, block(BL, [Decls, NewProcs, NewBody], void)], void).

transform_proc(Routines, proc(L, [N, Ps, R, block(BL, [D, P, Body], void)], void),
               proc(L, [N, Ps, R, block(BL, [D, P, NewBody], void)], void)) :-
    routine_body(N, Routines, Body, NewBody).

routine_body(Name, Routines, compound(L, _, _), NewBody) :-
    memberchk(routine(Name, LSs, Loops, _), Routines),
    transform_seq(LSs, Loops, LSs1),
    unlabel_body(LSs1, L, NewBody).

                 /*******************************
                 *          ROUTINES            *
                 *******************************/

%   program_routines(+Typed, -Rs): Rs is a list of
%   r(Name, Body, AllVars, ExitVars).

program_routines(program(_, [_, block(_, [Decls, Procs, Body], _)], _), [Main|Rs]) :-
    decl_names(Decls, Globals),
    Main = r(main, Body, Globals, []),
    maplist(proc_routine(Globals), Procs, Rs).

proc_routine(Globals, proc(_, [Name, Params, R, block(_, [Decls, _, Body], _)], _),
             r(Name, Body, All, Exit)) :-
    findall(N, (member(param(_, [_, Ns, _], _), Params), member(N, Ns)), PNs),
    findall(N, (member(param(_, [var, Ns, _], _), Params), member(N, Ns)), VNs),
    decl_names(Decls, Locals),
    ( R == none -> Res = [] ; Res = [Name] ),
    foldl(union_list, [Globals, PNs, Locals, Res], [], All),
    foldl(union_list, [Globals, VNs, Res], [], Exit).

union_list(L, S0, S) :- sort(L, SL), ord_union(S0, SL, S).

decl_names(Decls, Names) :-
    findall(N, (member(var_decl(_, [Ns, _], _), Decls), member(N, Ns)), Names0),
    sort(Names0, Names).

analyse_routine(r(Name, Body, All, Exit), routine(Name, LSs, Loops, Reach)) :-
    label_body(Body, LSs),
    with_dataflow(LSs, All, Exit,
                  ( classify_loops(LSs, Loops),
                    findall(reach(V, S, U), reach(V, S, U), Reach0),
                    sort(Reach0, Reach) )).

                 /*******************************
                 *        TRANSFORMATION        *
                 *******************************/

transform_seq(LSs, Loops, LSs1) :-
    maplist(transform(Loops), LSs, LSs1).

transform(Loops, lbl(P, for(L, [V, F, T, D, B], Ty)), lbl(P, S)) :- !,
    (   memberchk(loop(P, _, parallel, Classes), Loops)
    ->  clauses(Classes, Clauses),
        S = omp_for(L, [V, F, T, D, B, Clauses], Ty)
    ;   transform_seq(B, Loops, B1),
        S = for(L, [V, F, T, D, B1], Ty)
    ).
transform(Loops, lbl(P, while(L, [C, B], Ty)), lbl(P, while(L, [C, B1], Ty))) :- !,
    transform_seq(B, Loops, B1).
transform(Loops, lbl(P, repeat(L, [B, C], Ty)), lbl(P, repeat(L, [B1, C], Ty))) :- !,
    transform_seq(B, Loops, B1).
transform(Loops, lbl(P, if(L, [C, T, E], Ty)), lbl(P, if(L, [C, T1, E1], Ty))) :- !,
    transform(Loops, T, T1),
    transform(Loops, E, E1).
transform(Loops, lbl(P, compound(L, [B], Ty)), lbl(P, compound(L, [B1], Ty))) :- !,
    transform_seq(B, Loops, B1).
transform(_, S, S).

%!  clauses(+Classes, -Clauses) is det.
%
%   Map the paper's variable categories to OpenMP data-sharing clauses.
clauses(Classes, Clauses) :-
    findall(V, member(V-local, Classes), Private),
    findall(V, ( member(V-C, Classes), memberchk(C, [read_only, distributed]) ), Shared),
    findall(Op-V, member(V-associative(Op), Classes), OpVs),
    keysort(OpVs, Sorted),
    group_pairs_by_key(Sorted, Groups),
    findall(reduction(Op, Vs), member(Op-Vs, Groups), Reductions),
    exclude(==(private([])), [private(Private)], P1),
    exclude(==(shared([])), [shared(Shared)], S1),
    append([P1, S1, Reductions], Clauses).
```

```prolog
/** <module> C code generation

Emits C99 + OpenMP from a typed tree (with or without omp_for nodes).
Written as a DCG over the output codes, so each generator is a pure
relation from tree to text and can be unit tested.

Mapping (spec section 6.5):

  - integer, real, boolean   -> long, double, bool
  - array(Lo, Hi, E)          -> typedef struct { E e[Hi-Lo+1]; } pppc_tN
                                 (a struct so arrays have value semantics:
                                 assignment and value parameters copy)
  - record([F-T, ...])        -> typedef struct { T F; ... } pppc_tN
  - main program variables    -> file-scope static variables
  - var parameters            -> pointers, referenced as (*x)
  - function result           -> local pppc_result, returned at the end
  - for bounds                -> evaluated once into pppc_hi / pppc_lo
*/

%!  generate_c(+Typed, -CText:string) is det.
generate_c(Typed, Text) :-
    type_names(Typed, Types),
    phrase(program(Typed, Types), Codes),
    string_codes(Text, Codes).

%!  c_expr(+TypedExpr, -CText:string) is det.
%!  c_stmt(+TypedStmt, -CText:string) is det.
%
%   Generate code for a single expression or statement (indent 0),
%   for testing. Types used are declared on the fly.
c_expr(E, Text) :-
    type_names(E, Types),
    phrase(expr(E, Types), Codes),
    string_codes(Text, Codes).
c_stmt(S, Text) :-
    type_names(S, Types),
    phrase(stmt(S, 0, Types), Codes),
    string_codes(Text, Codes).

                 /*******************************
                 *        OUTPUT HELPERS        *
                 *******************************/

%   fmt(+Format, +Args)// emits format/2 output into the DCG list.
fmt(F, As, S0, S) :- format(codes(S0, S), F, As).

atom(A) --> fmt("~w", [A]).

indent(N) --> { N =< 0 }, !.
indent(N) --> "    ", { N1 is N - 1 }, indent(N1).

line_comment(L) --> fmt(" /* line ~d */", [L]).

sep_list([], _, _) --> [].
sep_list([X], G, _) --> !, call(G, X).
sep_list([X|Xs], G, Sep) --> call(G, X), Sep, sep_list(Xs, G, Sep).

                 /*******************************
                 *            TYPES             *
                 *******************************/

%   type_names(+Tree, -Types): an assoc from every compound type
%   occurring in Tree to its typedef name, plus `order` mapped to the
%   types in an order where components precede their users.

type_names(Tree, Types) :-
    findall(T, (sub_term(T, Tree), compound_type(T)), Ts0),
    foldl(add_type, Ts0, []-0, Ordered-_),
    reverse(Ordered, Order),
    pairs_to_assoc(Order, A0),
    type_keys(Order, Keys),
    put_assoc('$order', A0, Keys, Types).

compound_type(array(_, _, _)).
compound_type(record(_)).

add_type(T, Acc0-N0, Acc-N) :-
    (   memberchk(T-_, Acc0)
    ->  Acc = Acc0, N = N0
    ;   components(T, Cs),
        foldl(add_type, Cs, Acc0-N0, Acc1-N1),
        N is N1 + 1,
```

```prolog
:- module(pppc,
          [ pppc_compile/3,             % +File, +Options, -CText
            pppc_stage/3,               % +File, +Stage, -Result
            pppc_report/2               % +File, -Lines
          ]).
:- use_module(library(option)).
:- use_module(library(apply)).
:- use_module(library(lists)).
:- use_module(library(readutil)).
:- use_module(library(pppc/lexer)).
:- use_module(library(pppc/parser)).
:- use_module(library(pppc/semantic)).
:- use_module(library(pppc/transform)).
:- use_module(library(pppc/codegen)).
:- use_module(library(pppc/messages), []).

/** <module> PPPC: a portable parallelizing Pascal compiler

Reproduction of Gabber's PPPC (The Practice of Prolog, 1990, ch. 4)
targeting C + OpenMP. The passes are run in-process:

    lexer -> parser -> semantic -> [parallelizer] -> codegen

Errors in the source are thrown as pppc(Error) where Error is
no_source, syntax(Line, Expected, Found) or
semantic_errors(List); a failing or
crashing pass throws pppc(internal(Pass, Reason)).
*/

%!  pppc_compile(+File, +Options, -CText:string) is det.
%
%   Compile the TAU-Pascal program in File to C. Options:
%
%     - serial(Bool)  if `true`, skip the parallelizer.
pppc_compile(File, Options, CText) :-
    front_end(File, Typed),
    (   option(serial(true), Options)
    ->  Program = Typed
    ;   pass(parallelizer, parallelize_program(Typed, Program, _))
    ),
    pass(codegen, generate_c(Program, CText)).

%!  pppc_stage(+File, +Stage, -Result) is det.
%
%   Run the compiler up to Stage and return its output. Stage is one
%   of tokens, parse, typed, labelled, reach, parallel. For labelled
%   and reach, Result is a list Routine-Value.
pppc_stage(File, tokens, Ts) :- !,
    read_source(File, Codes),
    pass(lexer, tokenize(Codes, Ts)).
pppc_stage(File, parse, Tree) :- !,
    pppc_stage(File, tokens, Ts),
    pass(parser, parse_program(Ts, Tree)).
pppc_stage(File, typed, Typed) :- !,
    front_end(File, Typed).
pppc_stage(File, labelled, Pairs) :- !,
    analysis(File, Rs),
    findall(N-L, member(routine(N, L, _, _), Rs), Pairs).
pppc_stage(File, reach, Pairs) :- !,
    analysis(File, Rs),
    findall(N-R, member(routine(N, _, _, R), Rs), Pairs).
pppc_stage(File, parallel, Program) :- !,
    front_end(File, Typed),
    pass(parallelizer, parallelize_program(Typed, Program, _)).
pppc_stage(_, Stage, _) :-
    domain_error(pppc_stage, Stage).

%!  pppc_report(+File, -Lines:list(string)) is det.
%
%   One line per for loop:
%
%       Routine Line parallel Var:Class ...
%       Routine Line serial Reason ...
%       Routine Line nested OuterLine
pppc_report(File, Lines) :-
    analysis(File, Rs),
    findall(Line, ( member(routine(N, _, Loops, _), Rs),
                    member(Loop, Loops),
                    report_line(N, Loop, Line) ),
            Lines).

report_line(R, loop(_, L, parallel, Classes), Line) :-
    msort(Classes, Sorted),
    maplist([V-C, S]>>format(string(S), "~w:~w", [V, C]), Sorted, Ss),
    atomic_list_concat(Ss, ' ', Text),
    format(string(Line), "~w ~w parallel ~w", [R, L, Text]).
report_line(R, loop(_, L, serial(Reasons), _), Line) :-
    maplist([X, S]>>format(string(S), "~w", [X]), Reasons, Ss),
    atomic_list_concat(Ss, ' ', Text),
    format(string(Line), "~w ~w serial ~w", [R, L, Text]).
report_line(R, loop(_, L, nested(O), _), Line) :-
    format(string(Line), "~w ~w nested ~w", [R, L, O]).

                 /*******************************
                 *          PIPELINE            *
                 *******************************/

front_end(File, Typed) :-
    pppc_stage(File, parse, Tree),
    pass(semantic, check_program(Tree, Typed, Errors)),
    (   Errors == []
    ->  true
    ;   throw(pppc(semantic_errors(Errors)))
    ).

analysis(File, Routines) :-
    front_end(File, Typed),
    pass(parallelizer, analyse_program(Typed, Routines)).

read_source(File, Codes) :-
    catch(read_file_to_codes(File, Codes, []),
          error(existence_error(source_sink, _), _),
          throw(pppc(no_source))).

%   pass(+Name, :Goal): run one compiler pass deterministically.
%   Source errors (pppc(_) exceptions) pass through; anything else is
%   an internal error of that pass.
:- meta_predicate pass(+, 0).

pass(Name, Goal) :-
    catch(Goal, E, internal_error(Name, E)),
    !.
pass(Name, _) :-
    throw(pppc(internal(Name, failed))).

internal_error(_, pppc(E)) :- !, throw(pppc(E)).
internal_error(Name, E) :- throw(pppc(internal(Name, E))).
```

```prolog
run(File, Options) :-
```

```pascal
program linear;

const n = 250; eps = 1.0e-10;
var a: array[1..n, 1..n] of real;
    b: array[1..n] of real;

begin
  for i := 1 to n do
  begin
    for j := 1 to n do
      a[i, j] := 1.0 / (i + j);
    a[i, i] := n + 1.0;
    b[i] := i;
    x[i] := 0.0

    error := 0;
    for i := 1 to n do
    begin
      sum := 0;
      for j := 1 to n do

      new_x[i] := x[i] + (b[i] - sum) / a[i, i];
      error := error max abs(b[i] - sum)
    end;
    x := new_x;
    iter := iter + 1
  until error < eps;
  writeln('iterations = ', iter);
  sum := 0;
  for i := 1 to n do sum := sum + x[i];
  writeln('sum x = ', sum)
```

```pascal
var px, py, pz, vx, vy, vz, ax, ay, az, m: vec;
    i, j, s: integer;

  begin
    px[i] := cos(i);
    py[i] := sin(i);

    vx[i] := 0;
    vy[i] := 0;
    vz[i] := 0;
    m[i] := 1.0 / n
  end;

      fx := 0;
      fy := 0;
      fz := 0;

          dy := py[j] - py[i];
          dz := pz[j] - pz[i];
          d2 := dx * dx + dy * dy + dz * dz + soft;
          inv := m[j] / (d2 * sqrt(d2));
          fx := fx + dx * inv;
          fy := fy + dy * inv;
          fz := fz + dz * inv
        end;

      ay[i] := fy;
      az[i] := fz

      pz[i] := pz[i] + dt * vz[i]
```

```pascal
program cg;
{ conjugate gradient for a symmetric positive definite 250 x 250 system }
const n = 250; maxit = 1000; tol = 1.0e-20;
type vec = array[1..n] of real;
var a: array[1..n, 1..n] of real;
    b, x, r, p, q: vec;
    i, j, it: integer;
    rr, rr_new, pq, alpha, beta, s: real;
begin
  for i := 1 to n do
  begin
    for j := 1 to n do
      a[i, j] := 1.0 / (1 + abs(i - j));
    a[i, i] := a[i, i] + n;
    b[i] := 1.0;
    x[i] := 0;
    r[i] := b[i];
    p[i] := b[i]
  end;
  rr := 0;
  for i := 1 to n do
    rr := rr + r[i] * r[i];
  it := 0;
  while (it < maxit) and (rr > tol) do
  begin
    for i := 1 to n do
    begin
      s := 0;
      for j := 1 to n do
        s := s + a[i, j] * p[j];
      q[i] := s
    end;
    pq := 0;
    for i := 1 to n do
      pq := pq + p[i] * q[i];
    alpha := rr / pq;
    rr_new := 0;
    for i := 1 to n do
    begin
      x[i] := x[i] + alpha * p[i];
      r[i] := r[i] - alpha * q[i];
      rr_new := rr_new + r[i] * r[i]
    end;
    beta := rr_new / rr;
    rr := rr_new;
    for i := 1 to n do
      p[i] := r[i] + beta * p[i];
    it := it + 1
  end;
  s := 0;
  for i := 1 to n do
    s := s + x[i];
  writeln('iterations = ', it);
  writeln('sum x = ', s)
end.
```

Create `test/e2e.plt`:

```prolog
:- use_module(library(pppc)).
:- use_module(library(process)).
:- use_module(library(readutil)).
:- use_module(library(filesex)).
:- use_module(library(apply)).
:- use_module(library(lists)).

/** <module> End-to-end tests

Run from the project root inside the devenv shell: make check

For every program in test/programs and test/programs/negative:

  1. the --report output equals the checked-in .report file;
  2. the serial and parallel C build with gcc -O2 -fopenmp;
  3. the parallel binary run with OMP_NUM_THREADS=1 and 4 prints the
     same as the serial binary (numbers within a relative tolerance
     of 1e-9), except montepi, whose result must be within 0.01 of pi.
*/

:- begin_tests(e2e).

%   program(-Pas) enumerates the test programs. Paths are relative to
%   the project root, where `make check` runs.
program(Pas) :-
    member(Dir, ['test/programs', 'test/programs/negative']),
    directory_files(Dir, Fs), msort(Fs, Sorted),
    member(F, Sorted), file_name_extension(_, pas, F),
    directory_file_path(Dir, F, Pas).

test(report, [forall(program(Pas))]) :-
    pppc_report(Pas, Lines),
    file_name_extension(Base, pas, Pas),
    file_name_extension(Base, report, Expected),
    read_file_to_string(Expected, Text, []),
    split_string(Text, "\n", "", Parts), exclude(==(""), Parts, ExpectedLines),
    assertion(Lines == ExpectedLines).

test(run, [forall(program(Pas))]) :-
    build(Pas, serial, Serial),
    build(Pas, parallel, Parallel),
    run(Serial, 1, Reference),
    run(Parallel, 1, Out1),
    run(Parallel, 4, Out4),
    file_base_name(Pas, File), file_name_extension(Name, _, File),
    check(Name, Reference, Out1),
    check(Name, Reference, Out4).

build(Pas, Mode, Exe) :-
    file_base_name(Pas, File), file_name_extension(Name, _, File),
    make_directory_path('build/e2e'),
    format(atom(C), 'build/e2e/~w_~w.c', [Name, Mode]),
    format(atom(Exe), 'build/e2e/~w_~w', [Name, Mode]),
    ( Mode == serial -> Opts = [serial(true)] ; Opts = [] ),
    pppc_compile(Pas, Opts, Code),
    setup_call_cleanup(open(C, write, S), write(S, Code), close(S)),
    process_create(path(gcc), ['-O2', '-Wall', '-Werror', '-fopenmp', C, '-o', Exe, '-lm'],
                   [stderr(pipe(Err)), process(Pid)]),
    read_string(Err, _, Diag), close(Err),
    process_wait(Pid, Status),
    assertion(Status-Diag == exit(0)-"").

run(Exe, Threads, Output) :-
    process_create(Exe, [], [ stdout(pipe(Out)), process(Pid),
                              environment(['OMP_NUM_THREADS'=Threads]) ]),
    read_string(Out, _, Output), close(Out),
    process_wait(Pid, Status),
    assertion(Status == exit(0)).

check(montepi, _, Out) :- !,
    last_number(Out, Pi),
    assertion(abs(Pi - pi) < 0.01).
check(_, Reference, Out) :-
    split_string(Reference, " \n", " \n", Ws1),
    split_string(Out, " \n", " \n", Ws2),
    assertion(maplist(same_word, Ws1, Ws2)).

same_word(W, W) :- !.
same_word(W1, W2) :-
    number_string(X, W1), number_string(Y, W2),
    abs(X - Y) =< 1.0e-9 * max(abs(X), abs(Y)).

last_number(Out, N) :-
    split_string(Out, " \n", " \n", Ws),
    include([W]>>number_string(_, W), Ws, Ns),
    last(Ns, Last), number_string(N, Last).

:- end_tests(e2e).
```
